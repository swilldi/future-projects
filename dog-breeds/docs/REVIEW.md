# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Обучение

- [ ] Только скриптом, сид фиксирован, данные вне репозитория.
- [ ] Класс «другое» присутствует и разнообразен.
- [ ] Точность и матрица ошибок записаны, модель с метаданными.

## Кадры

- [ ] `AsyncStream` с `bufferingNewest(1)`.
- [ ] Троттлинг по времени и занятости, тесты.
- [ ] Ориентация передаётся в Vision явно.
- [ ] Реакция на тепловое состояние.

## Изоляция

- [ ] `DispatchQueue` только в `CameraSession`, с комментарием.
- [ ] Делегат не трогает UI.
- [ ] `Classifier` один, запрос один, модель загружена один раз.
- [ ] Классификация вне главного актора.

## Решение

- [ ] `Verdict` и `Smoother` без Vision, тесты на границах порогов.
- [ ] Пороги в одном файле.

## Данные

- [ ] Снимок уменьшен до сохранения, `externalStorage`.
- [ ] Удаление с подтверждением.

## Разрешения и края

- [ ] Камера запрашивается при открытии вкладки, отказ объяснён.
- [ ] Модель не загрузилась: ошибка, не краш.

## Доступность

- [ ] Оверлей результата читается VoiceOver.
- [ ] Кнопка снимка с подписью, сетка коллекции с описаниями.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, точность сверх записанной, поведение на старых устройствах без Neural Engine.
