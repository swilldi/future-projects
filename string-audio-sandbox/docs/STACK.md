# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| AVAudioEngine, AVAudioSourceNode | Вывод синтезированного звука | Граф узлов, формат, колбэк рендера, старт и стоп |
| AVAudioSession | Задержка и прерывания | Категории, буфер, `outputLatency`, уведомления |
| Карплус-Стронг | Синтез струны | Почему буфер задержки со сглаживанием звучит как струна, что дают затухание и фильтр |
| `Synchronization.Atomic` | Обмен с аудиопотоком | Порядок памяти, чего хватает для SPSC-очереди |
| `UnsafeMutableBufferPointer` | Буферы без ARC | Выделение один раз, время жизни, почему не `Array` |
| SwiftUI `Canvas`, `DragGesture` | Струна на экране | Ничего нового |
| Instruments: Allocations, Time Profiler | Проверка реального времени | Как отфильтровать аудиопоток и увидеть аллокации |

## Чего нет и почему

- AudioKit и подобных. Цель увидеть уровень ниже.
- Сэмплов. Синтез это и есть предмет.
- Core Haptics. Будет в «Струнах».

## Что почитать и посмотреть

**Перед фазой 1:**
- Статья Росса Бенсины «Real-time audio programming 101: time waits for nothing». Обязательно, это правила игры.
- Julius O. Smith, «Physical Audio Signal Processing», глава про Karplus-Strong. Онлайн, бесплатно, читать только эту главу.
- Статья в Википедии про алгоритм Карплуса-Стронга, для картинки.

**Перед фазой 2:**
- Документация: `AVAudioSourceNode`, пример Apple «Building a Signal Generator».
- Документация: «Configuring your app for media playback», раздел про аудиосессию и задержку.

**Перед фазой 3:**
- Документация Swift: модуль `Synchronization`, `Atomic`.

**Перед фазой 6:**
- Документация Instruments: «Allocations», «Time Profiler». Раздел про фильтрацию по потоку.
