# Спецификация: «Страны»

Общее техзадание для всех десяти полигонов архитектур. Одинаковое во всех папках, меняется только раскладка кода. Если по ходу одного полигона захотелось поменять требования, не менять: сравнение работает только на одинаковой задаче.

## Одним абзацем

Справочник стран. Список с флагом, названием и столицей, поиск по названию, обновление из сети. Экран деталей с кнопкой «в избранное». Список избранного, который переживает перезапуск. Последний загруженный список кэшируется: при старте показывается из кэша и обновляется из сети. Без дизайна: системные компоненты, всё внимание на структуру.

## Навигация

Две вкладки: «Страны» и «Избранное». Из обеих детали открываются пушем. Итого три экрана.

## Экраны

### Список

- Ячейка: маленький флаг, название, столица.
- Поиск по названию: локальный, без сети, по мере ввода. Регистр и диакритика не важны.
- Обновление: заново из сети, кэш перезаписывается. Жест pull-to-refresh.
- Состояния: загрузка (только если кэша нет), ошибка с кнопкой «повторить» (только если кэша нет; если кэш есть, ошибка показывается тихо поверх списка), пустой результат поиска.
- Выбор страны открывает детали.

### Детали

- Флаг крупно, название, официальное название, столица (или «нет»), регион и субрегион, население, площадь, валюты, языки.
- Кнопка «в избранное» и «убрать из избранного». Состояние отражается сразу везде, где эта страна видна.

### Избранное

- Те же ячейки, что в списке. Порядок по названию.
- Пусто: подсказка «добавьте страну из деталей».
- Выбор открывает детали.

## Данные

Источник: restcountries.com, версия 3.1. Один запрос отдаёт все страны, около 250 записей. Параметр `fields` обязателен, без него сервер отвечает ошибкой:

```
https://restcountries.com/v3.1/all?fields=cca3,name,capital,region,subregion,population,area,flags,currencies,languages
```

Запасной источник, если основной лёг: PokeAPI, список покемонов с деталями. Структура экранов та же, меняются только модели.

Кэш: последний успешный ответ целиком в JSON-файл в Caches. При старте: есть кэш, показать его и обновить из сети в фоне; кэша нет, показать загрузку.

Избранное: набор кодов `cca3` в JSON-файле в Documents. Не в Caches, потому что Caches система может почистить.

Флаги: PNG по ссылке из ответа, грузятся системными средствами, свой кэш картинок не пишется.

## Сущности

```
CountryDTO              // ровно то, что отдаёт API, Decodable

Country                 // то, с чем работают экраны
  code: String          // cca3
  name: String          // name.common
  officialName: String  // name.official
  capital: [String]     // пустой или несколько
  region: String
  subregion: String?
  population: Int
  area: Double
  flagURL: URL          // flags.png
  currencies: [String]  // названия
  languages: [String]   // названия

Favorites
  codes: Set<String>
```

DTO и `Country` разделены во всех полигонах. Маппинг живёт рядом с DTO.

## Границы

- Страна без столицы (Антарктида): показать «нет».
- Несколько столиц (ЮАР): через запятую.
- Нет валют или языков: скрыть строку.
- Флаг не загрузился: серый прямоугольник, без ошибки.
- Сеть недоступна, кэша нет: экран ошибки с повтором.
- Сеть недоступна, кэш есть: список из кэша и тихий индикатор «офлайн».
- Поиск «cote» находит «Côte d'Ivoire».
- Повреждённый файл кэша или избранного: считать пустым, не падать.

## Не делаем

- Пагинацию, сортировку, фильтры по региону.
- Авторизацию.
- Кастомный дизайн, анимации, тёмную тему сверх системной.
- Локализацию. Интерфейс на русском, названия стран на английском, как отдаёт API.
- Кэш картинок.
- Раскладку под iPad.

## Готово, когда

- Три экрана работают на устройстве.
- Запуск без сети с кэшем показывает список.
- Избранное переживает перезапуск.
- Логика, которую архитектура объявляет тестируемой, покрыта тестами.
- Строка в таблице сравнения в корневом индексе заполнена.
