# Страны: Clean Architecture

Полигон 7 из 10. Одно и то же приложение «Страны», десять раскладок кода. Здесь: **Clean Architecture со слоями Domain, Data, Presentation и MVVM сверху, SwiftUI**.

Не про экран, а про слои. Domain: сущности, протоколы репозиториев, use case-ы. Data: реализации репозиториев, сеть, файлы, DTO и маппинги. Presentation: SwiftUI и ViewModel из полигона MVVM. Каждый слой это отдельный локальный Swift-пакет, и правило зависимостей проверяет компилятор.

## Зачем

Понять правило зависимостей на ощупь: домен не знает ни о сети, ни о UI, и это не договорённость, а невозможность импорта. И честно измерить цену: сколько типов нужно, чтобы показать список из 250 стран, и где граница, за которой это перестаёт окупаться.

## Что хочу понять

- Три локальных пакета и зависимости в `Package.swift` как способ навязать архитектуру.
- Use case как единица бизнес-логики: когда он нужен, когда он просто пересылает.
- Репозиторий как граница домена: протокол в Domain, реализация в Data.
- Маппинг DTO в сущность и почему домен не должен видеть JSON.
- Composition root: сборка всего графа в одном месте руками.
- Не путать с Clean Swift из предыдущего полигона: общее только слово.

## Что делает приложение

Справочник стран: список с флагом и столицей, поиск, обновление из сети, детали с кнопкой «в избранное», список избранного, кэш для запуска без сети. Полное ТЗ в `docs/SPEC.md`, оно одинаково для всех десяти полигонов.

## Готово, когда

- Три экрана работают на устройстве, запуск без сети с кэшем показывает список, избранное переживает перезапуск.
- То, что эта архитектура объявляет тестируемым (см. `docs/ARCHITECTURE.md`), покрыто тестами.
- Агент прошёл по `docs/REVIEW.md`, блокеров нет.
- В корневом индексе заполнена строка сравнения, а в `docs/NOTES.md` ответы на вопросы из раздела «Что записать в сравнение».

## Как начать

1. `docs/SPEC.md`: прочитать целиком, если это первый полигон, иначе пробежать, оно не менялось.
2. `docs/ARCHITECTURE.md`: прочитать целиком. Это единственное, что здесь отличается от соседей.
3. `docs/STACK.md`: раздел «что почитать» перед соответствующей фазой.
4. `docs/PLAN.md`: идти по фазам. `Services/` можно скопировать из предыдущего полигона.
5. `docs/NOTES.md`: по ходу записывать, что бесит и что нравится. Это и есть результат.

## Оценка

Три-четыре дня. Пакеты и маппинги требуют времени, даже когда логики мало.
