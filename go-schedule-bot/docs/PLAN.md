# План

Фазы идут по порядку. Каждая заканчивается рабочим состоянием и коммитом. «Вопросы себе» это то, на что я должен уметь ответить после фазы, не заглядывая в документацию. Не могу ответить, значит фаза не закончена.

Где звать агента, отмечено значком 🤖. В остальных местах не звать.

## Фаза 0. Эхо-бот в контейнере

- [ ] Модуль, `config`, библиотека Telegram, эхо на любое сообщение.
- [ ] `Dockerfile`, `compose.yaml` с `.env`, бот отвечает из контейнера.
- [ ] `Makefile`, линтер, `.gitignore` с `.env`, первый коммит.

Вопросы себе: как long polling работает без публичного адреса? Что произойдёт, если запустить два экземпляра с одним токеном?

Готово, когда бот отвечает эхом из контейнера.
