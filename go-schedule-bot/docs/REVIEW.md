# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `go vet` и `golangci-lint` чисты.
- [ ] `go test -race ./...` зелёный.
- [ ] Образ собирается, `docker compose up` поднимает всё одной командой.

## Горутины

- [ ] Каждая долгоживущая горутина принимает контекст и завершается по отмене, тест есть.
- [ ] `for-select` циклы с тикерами останавливают тикер.
- [ ] `errgroup` не роняет всё из-за ошибки источника.
- [ ] Порядок остановки: опрос, планировщик, кэш, база.

## Данные

- [ ] Кэш под `RWMutex`, отдаёт копии.
- [ ] SQLite с WAL и `busy_timeout`, один писатель.
- [ ] `-race` чист.

## Источники

- [ ] За интерфейсом, домен их не различает.
- [ ] Тесты на записанных ответах.
- [ ] Ошибка обновления не затирает кэш, ретраи с ростом.

## Планировщик

- [ ] Часы через интерфейс, `time.Now` только в `clock.Real`.
- [ ] `sent` защищает от повторов после перезапуска.
- [ ] Пропущенные по правилу, прошедшие не шлются.
- [ ] Блокировка бота отключает подписку.

## Команды

- [ ] Обработчик без Telegram-типов, тесты таблицей.
- [ ] Пояса валидируются, `tzdata` в бинарнике.
- [ ] Ошибки человеческим языком.

## Секреты и контейнер

- [ ] Токен из окружения, в логах маскирован, `.env` в `.gitignore`.
- [ ] База в томе, образ без компилятора.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Доступность splatoon3.ink в будущем, групповые чаты, локализацию.
