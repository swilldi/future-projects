# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Горутины, каналы, `select` | Долгоживущие компоненты | Тикеры, отмена, завершение, `for-select` цикл |
| `context` | Время жизни | Дерево контекстов от `main` до запроса |
| `sync.RWMutex`, `errgroup` | Общие данные и группа | Копии при чтении, первая ошибка в группе |
| Библиотека Telegram-бота | Обновления и отправка | Long polling, обработчики, `retry_after` |
| `modernc.org/sqlite` | База | Драйвер без cgo, WAL, `busy_timeout`, один писатель |
| `time.Location`, `time/tzdata` | Пояса | Загрузка поясов, встраивание базы в бинарник |
| Интерфейс `Clock` | Тесты | Фальшивые часы вместо ожидания |
| Табличные тесты | Команды и планировщик | Кортежи входа и ожидания |
| Docker, том | Развёртывание | Персистентный файл базы, `.env` с токеном |

## Чего нет и почему

- Вебхуков: нужен публичный адрес.
- Postgres: SQLite достаточно и это другой опыт.
- Фреймворков для команд: `switch` по строке.
