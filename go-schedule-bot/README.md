# Бот расписания

Бот в Telegram, которому пишешь `/next` и получаешь, что дальше по расписанию: следующая ротация режимов в Splatoon 3 или ближайшая сессия гоночного уикенда. `/subscribe 30` и бот сам напомнит за полчаса. Источник расписания это адаптер, их два, переключается настройкой. Работает в контейнере на любом сервере.

## Зачем

Второй проект на Go и первый с тем, ради чего Go придумали: несколько горутин, которые живут долго и общаются каналами. Опрос Telegram, опрос источника, планировщик напоминаний, отправка. Плюс SQLite вместо Postgres, чтобы увидеть другую базу, и деплой бота как самый практичный сценарий для контейнера.

## Что будет в первой версии

- Команды: `/next`, `/today`, `/subscribe N`, `/unsubscribe`, `/tz Europe/Moscow`, `/source`, `/help`.
- Два источника за одним интерфейсом: Splatoon 3 через splatoon3.ink, Формула-1 через Jolpica.
- Планировщик: горутина проверяет ближайшие события и шлёт напоминания подписчикам за N минут.
- Подписки и часовые пояса в SQLite.
- Long polling без вебхуков и публичного адреса.
- Кэш расписания с обновлением по интервалу, работа при недоступном источнике.
- Docker, конфигурация через окружение, корректное завершение.
- Тесты с фикстурами источников и фальшивыми часами.

## Готово, когда

- Бот прожил неделю в контейнере: напоминания приходили вовремя, память не росла.
- Источник недоступен час: бот отвечает из кэша и пишет об этом, после возврата догоняет.
- `go test -race` зелёный, планировщик покрыт тестами с фальшивыми часами без реального ожидания.
- Перезапуск не теряет подписки и не шлёт напоминания дважды.
- `docker compose up` на чистой машине с одним токеном в `.env`.
