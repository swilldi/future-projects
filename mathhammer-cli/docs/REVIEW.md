# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `swift build` и `swift test` зелёные на macOS и в Docker на Linux.
- [ ] Без warnings. swift-format ничего не меняет.

## Вероятности

- [ ] `Distribution` держит инвариант суммы, тест есть.
- [ ] Сравнение `Double` только с допуском.
- [ ] Хвосты обрезаются с записанным порогом, и это не меняет ожидание больше допуска.

## Правила

- [ ] Каждое правило в `Rules/` с комментарием-источником.
- [ ] Перебросы до модификатора, естественные 1 и 6 обработаны.
- [ ] Sustained, Lethal, Devastating, крит, Torrent, Blast покрыты тестами по отдельности и парами.
- [ ] Таблица ранений на все пять случаев.

## Модели

- [ ] Убитые модели через цепь состояний, лишний урон пропадает, тест есть.
- [ ] `--models 0` не считает убитых.

## Симулятор

- [ ] Независимая реализация, не зовёт `Rules/`.
- [ ] Генератор передаётся, сид воспроизводит результат.
- [ ] Тест сходимости на пяти профилях.

## Команда и платформы

- [ ] Флаги валидируются, ошибки понятны, коды выхода по `SPEC.md`.
- [ ] Ядро без Foundation, кроме файла ввода JSON.
- [ ] Тесты зелёные в Docker.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Полноту правил игры сверх перечисленных, производительность на экстремальных профилях.
