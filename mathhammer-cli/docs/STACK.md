# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Swift Package, два таргета | Библиотека и команда | Продукты, зависимости таргетов, `swift run` |
| swift-argument-parser | Флаги | `@Option`, `@Flag`, валидация, справка, коды выхода |
| Свёртка и биномиальное | Точный расчёт | Как складываются независимые распределения, почему это `O(n·m)` |
| Марковская цепь | Убитые модели | Состояние, переходы, почему свёртка тут не работает |
| `RandomNumberGenerator` | Монте-Карло | Свой генератор с сидом для воспроизводимости |
| Swift Testing параметризованный | Таблицы правил | `@Test(arguments:)` с кортежами |
| Docker `swift:6` | Linux | Что в Foundation отсутствует |
| `swift build -c release` | Релиз | Оптимизации, размер, `strip` |
| Homebrew formula | Установка | Стретч: tap, формула, `brew install` |

## Чего нет и почему

- Библиотек для статистики. Свёртка в двадцать строк.
- Foundation в ядре, где можно без него.
