# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Модель

- [ ] Все свойства `Book` с значениями по умолчанию или опциональные.
- [ ] Нет `@Attribute(.unique)`, нет обязательных связей.
- [ ] Обложка через `externalStorage`, уменьшена до вставки.

## ISBN и данные

- [ ] `ISBN` единственный путь к строке для хранения, тесты на суммы.
- [ ] Провайдеры принимают конфигурацию сессии, тесты на фикстурах.
- [ ] Цепочка провайдеров, первый непустой.
- [ ] Дубликат проверяется запросом до вставки.
- [ ] Сеть не на главном акторе.

## CloudKit

- [ ] Entitlements и контейнер настроены, схема развёрнута.
- [ ] Проверено на двух устройствах, включая офлайн-правки.
- [ ] Без аккаунта приложение работает.

## Платформы

- [ ] `#if os` только в трёх местах.
- [ ] На Mac нет кнопки сканирования, есть команды меню.
- [ ] `NavigationSplitView` и `TabView` через `PlatformLayout`.

## Сканер

- [ ] Только EAN-13, остальное с подсказкой.
- [ ] `isSupported` и `isAvailable` проверены.
- [ ] Описание камеры в plist.

## Доступность

- [ ] Обложки с описанием, оценка доступна как слайдер.
- [ ] Список читается с названием, автором, статусом.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, скорость синхронизации, поведение при смене аккаунта iCloud.
