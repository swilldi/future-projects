# Спецификация

## Одним абзацем

Библиотека книг. Добавить книгу сканом или вводом ISBN, метаданные подтягиваются. Полки по статусу. Всё синхронизируется через iCloud. iPhone для сканирования, Mac и iPad для просмотра и правок.

## Экраны

### Полки

- Боковая панель на Mac и iPad, вкладки на iPhone: все, хочу, читаю, прочитано.
- Список книг: обложка, название, авторы, год, статус значком, оценка звёздами.
- Поиск по названию и авторам. Сортировка: по дате добавления, названию, автору, оценке.
- Кнопка «Добавить»: на iOS выбор «сканировать» или «ввести ISBN», на Mac только ввод.
- Пусто: подсказка с кнопкой добавить.

### Добавление

- Сканер: `DataScannerViewController` с фильтром на EAN-13, подсветка найденного, тап или автоматически через секунду стабильного распознавания.
- Ввод: поле ISBN с проверкой на лету, ошибка контрольной суммы.
- После получения ISBN: загрузка метаданных, превью с обложкой, кнопка «На полку» с выбором статуса. Если метаданных нет: форма ручного ввода с ISBN.

### Книга

- Обложка крупно, название, авторы, год, страницы, ISBN.
- Статус сегментом, оценка звёздами, заметки, даты начала и окончания чтения.
- Изменения сохраняются сразу.
- Удалить с подтверждением. Обновить метаданные.

## ISBN

- ISBN-13: 13 цифр, начинается с 978 или 979, контрольная сумма по весам 1 и 3.
- ISBN-10: 10 символов, последний может быть X, сумма с весами 10…1 кратна 11.
- Дефисы и пробелы игнорируются. ISBN-10 конвертируется в 13 для хранения.
- Хранится всегда ISBN-13.

## Метаданные

Open Library:

```
https://openlibrary.org/isbn/{isbn13}.json                     книга
https://openlibrary.org/authors/{key}.json                      автор, по ключам из книги
https://covers.openlibrary.org/b/isbn/{isbn13}-L.jpg            обложка, 404 если нет
```

Google Books, запасной: `https://www.googleapis.com/books/v1/volumes?q=isbn:{isbn13}`. Без ключа для базовых запросов.

Маппинг: название, авторы списком, год из строки даты, страницы, обложка байтами до 500 килобайт с уменьшением. Отсутствующие поля пустые.

## Синхронизация

- SwiftData с `cloudKitDatabase: .private("iCloud.<bundle>")`.
- Обложка в `@Attribute(.externalStorage)`.
- Конфликт правок: последняя запись побеждает, это принято и записано.
- Без iCloud-аккаунта: приложение работает локально, в настройках подсказка.

## Границы

- Штрихкод не EAN-13 (QR, другой товар): игнорируется, подсказка.
- ISBN валиден, но книги нет ни в одном источнике: ручная форма.
- Обложки нет: серая заглушка с первой буквой названия.
- Дубликат ISBN: предупреждение «уже на полке», переход к книге. Уникальность проверяется запросом, не ограничением модели.
- Mac без камеры: кнопка сканирования отсутствует, не отключена.
- Синхронизация отстаёт: индикатор не показываем, SwiftData не даёт статуса. Записано.

## Не делаем

- Публичные полки, шаринг.
- Экспорт.
- Цитаты, прогресс по страницам.
- Локализацию сверх русского.

## Сущности

```
@Model Book
  isbn13: String = ""
  title: String = ""
  authors: [String] = []
  year: Int? = nil
  pages: Int? = nil
  @Attribute(.externalStorage) coverData: Data? = nil
  status: BookStatus = .want         // want, reading, read; enum String
  rating: Int = 0                    // 0…5
  notes: String = ""
  addedAt: Date = .now
  startedAt: Date? = nil
  finishedAt: Date? = nil
```

Без `.unique`, без обязательных связей: требования CloudKit.
