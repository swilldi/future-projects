# Книжная полка

Наводишь камеру на штрихкод книги, приложение узнаёт ISBN, тянет название, авторов, год и обложку, кладёт на полку. Полки: хочу, читаю, прочитано. Оценка и заметки. На Mac то же приложение, ISBN вводится руками. Всё синхронизируется через iCloud без своего сервера.

## Зачем

Синхронизация через iCloud это то, что Apple даёт почти бесплатно, но с кучей ограничений на модель. SwiftData с CloudKit, сканер штрихкодов из VisionKit, один код на iOS и macOS с ветвлениями там, где платформы расходятся. Полезное приложение на реальной библиотеке.

## Что будет в первой версии

- Скан штрихкода EAN-13 через VisionKit на iOS, ввод ISBN руками на обеих платформах.
- Проверка ISBN-10 и ISBN-13 с контрольной суммой, конвертация.
- Метаданные из Open Library, запасной Google Books.
- Книга: название, авторы, год, страницы, обложка, ISBN, статус, оценка, заметки, даты.
- Полки: все, хочу, читаю, прочитано. Поиск и сортировка.
- SwiftData с синхронизацией через CloudKit, приватная база.
- Обложка как внешнее хранилище.
- iOS и macOS из одного таргета, `NavigationSplitView` на Mac и iPad.

## Готово, когда

- Двадцать книг с полки отсканированы за пять минут, обложки на месте.
- Книга, добавленная на iPhone, появляется на Mac в течение минуты, и наоборот. Правка на двух устройствах офлайн сходится без потери.
- ISBN и маппинг метаданных покрыты тестами.
- На Mac всё работает без камеры: ввод ISBN, поиск, редактирование.
- Ограничения модели для CloudKit соблюдены, и это проверено включением синхронизации на непустой базе.
