# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `swift build` и `swift test` зелёные на macOS и в Docker на Linux.
- [ ] Без warnings. swift-format ничего не меняет.

## Публичный API

- [ ] Каждый `public` задокументирован через `///`.
- [ ] DTO и `Transport` не публичные.
- [ ] Модели `Sendable`, `Hashable`, без классов, плоские.
- [ ] Ошибки несут контекст: статус, путь, `Retry-After`.
- [ ] Ни одно изменение в этой версии не ломает существующие сигнатуры, или версия мажорная.

## Транспорт

- [ ] `Transport/` не упоминает F1.
- [ ] Цикл повторов в одном месте, 4xx кроме 429 не повторяются.
- [ ] `Retry-After` соблюдается.
- [ ] Сон только через `Sleeper`, `Task.sleep` в библиотеке отсутствует.
- [ ] `URLSession.shared` в библиотеке отсутствует.
- [ ] Отмена задачи прерывает повторы.
- [ ] Лимит частоты актором, тест с записанными задержками.

## Маппинг

- [ ] Даты в UTC, разбор без локали.
- [ ] Отсутствующие сессии пропускаются, порядок по времени.
- [ ] Неизвестные поля игнорируются.

## Кроссплатформенность

- [ ] Тесты зелёные в Docker на Linux, или ограничения записаны и обоснованы.
- [ ] Нет API, отсутствующих в corelibs-foundation.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Актуальность данных API, производительность, команду `f1` юнитами.
