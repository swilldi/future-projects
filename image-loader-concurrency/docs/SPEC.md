# Спецификация

## Одним абзацем

Две вкладки. «Загрузчик»: сетка ста плиток, кнопки старт, отменить всё, повторить упавшие, слайдер лимита, панель статистики. «Лаборатория»: две кнопки, каждая запускает сто задач, инкрементирующих счётчик, одна без защиты, другая через актор, и показывает результат.

## Загрузчик

- Источник картинок: `https://picsum.photos/seed/<n>/600/600` для `n` от 1 до 100. Детерминированные, кэш URLSession отключён, чтобы каждый запуск грузил по-настоящему.
- Запасной источник: `https://placehold.co/600x600?text=<n>`.
- Плитка: серый квадрат, поверх состояние. Ожидание: пусто. Загрузка: кольцо прогресса, если сервер отдал размер, иначе неопределённый. Готово: уменьшенная картинка. Ошибка: красный крест, тап повторяет. Отменено: серый крест.
- Тап по загружающейся плитке отменяет только её.
- Слайдер лимита 1…16. Изменение во время загрузки применяется к следующим задачам.
- Статистика: прошло секунд, загружено, упало, отменено, байт всего, средняя скорость, пиковое число одновременных.
- «Старт» с текущими результатами сбрасывает всё и грузит заново.

## Обработка

- После загрузки данных картинка декодируется и уменьшается до 200 на 200 через `CGImageSourceCreateThumbnailAtIndex` с `kCGImageSourceThumbnailMaxPixelSize`. Не на главном акторе.
- Тяжёлая часть не блокирует ни главный актор, ни другие загрузки заметно: сто картинок с лимитом 8 не тормозят прокрутку.

## Лаборатория

- «Без защиты»: сто задач инкрементируют `nonisolated(unsafe) var counter`. Ожидаемо меньше ста. Thread Sanitizer ругается.
- «С актором»: сто задач инкрементируют через актор. Ровно сто.
- «Реентерабельность»: актор с `await` внутри метода, две задачи видят чужое промежуточное состояние. Демонстрация, что актор не мьютекс.

## Границы

- Сеть пропала посередине: текущие падают с ошибкой, остальные тоже, повтор работает после возврата сети.
- Лимит 1: строго по одной, видно глазами.
- Лимит 16: пик одновременных не больше 16.
- Отмена всего во время обработки картинки: обработка прерывается или доделывается, но результат не показывается.
- Уход с вкладки не отменяет загрузку. Возврат показывает актуальное состояние.

## Не делаем

- Кэш картинок на диске.
- Приоритизацию видимых плиток. Это стретч.
- Возобновление загрузки с середины.

## Сущности

```
ImageItem
  id: Int
  url: URL
  state: State        // waiting, loading(progress: Double?), done(bytes: Int), failed(String), cancelled

LoaderEvent
  case started(id)
  case progress(id, Double)
  case finished(id, image: CGImage, bytes: Int)
  case failed(id, Error)
  case cancelled(id)
  case concurrency(Int)  // текущее число одновременных, для пика
```
