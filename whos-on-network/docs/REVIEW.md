# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Чистая логика

- [ ] `DeviceMerger`, `ExpiryPolicy`, `ServiceCatalog` без Network.
- [ ] Тесты слияния на записанных событиях.
- [ ] Типы и имена сервисов только в каталоге.

## Сеть

- [ ] Только Bonjour, нет сканирования диапазонов и портов.
- [ ] Каждый браузер и соединение отменяются, `stop()` покрывает все.
- [ ] Разрешение адресов ограничено по частоте.
- [ ] Снимки раз в 500 мс, не на каждое событие.
- [ ] Состояние `waiting` с ошибкой политики показано пользователю.
- [ ] Дубли по интерфейсам отфильтрованы.

## Приватность

- [ ] Оба plist-ключа присутствуют, список типов совпадает с кодом.
- [ ] Ничего не сохраняется и не отправляется.

## Интерфейс

- [ ] Панели связаны только через оконный контроллер.
- [ ] Пустые состояния по `SPEC.md`.
- [ ] Закрытие окна останавливает сканер.

## Доступность

- [ ] Строки списка читаются с именем и статусом.
- [ ] Кнопка копирования с подписью.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, работу в чужих корпоративных сетях, точность эвристики значков.
