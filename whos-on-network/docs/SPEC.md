# Спецификация

## Одним абзацем

Окно, слева устройства, справа детали, в тулбаре фильтр и кнопка обновить. Приложение слушает Bonjour, собирает сервисы по хостам, разрешает адреса, показывает. Ничего не отправляет и не сохраняет.

## Обнаружение

- Мета-запрос `_services._dns-sd._udp` для списка типов сервисов в сети.
- На каждый найденный тип свой `NWBrowser`, плюс заранее известный список: `_airplay._tcp`, `_raop._tcp`, `_companion-link._tcp`, `_rdlink._tcp`, `_homekit._tcp`, `_hap._tcp`, `_smb._tcp`, `_ssh._tcp`, `_ipp._tcp`, `_ipps._tcp`, `_http._tcp`, `_googlecast._tcp`, `_spotify-connect._tcp`, `_sleep-proxy._udp`.
- Результат: имя сервиса, тип, домен, TXT-записи из метаданных, если есть.
- Устройство: ключ по имени хоста из разрешения или, если недоступно, по имени сервиса без суффикса типа. Все сервисы с одним ключом объединяются.
- Адреса: для каждого устройства одно разрешение через `NWConnection` к первому сервису, чтение удалённого адреса из пути, отмена соединения. Не чаще раза в минуту на устройство.
- Истечение: устройство без обновлений 60 секунд помечается «не отвечает», через 180 удаляется.

## Экран

### Список

- Строка: значок по типу (телефон, планшет, компьютер, телевизор, колонка, принтер, неизвестно), имя, количество сервисов, «видели 5 с назад».
- Значок по эвристике: наличие `_companion-link` и `_rdlink` это iPhone или iPad, `_airplay` с моделью в TXT это Apple TV или Mac, `_ipp` принтер, `_googlecast` колонка. Эвристика в каталоге.
- Сортировка: по имени. «Не отвечает» серым внизу.
- Фильтр в тулбаре по имени и типу сервиса.
- Пусто: «Ищем устройства…» первые десять секунд, потом «Ничего не найдено. Проверьте, что Wi-Fi тот же».

### Детали

- Имя, модель из TXT, если есть, адреса.
- Сервисы таблицей: тип, человеческое имя, порт, если известен.
- TXT-записи выбранного сервиса ключ-значение.
- Кнопка «Скопировать адрес».

### Тулбар

- Поле фильтра.
- Кнопка «Обновить»: перезапуск всех браузеров.
- Индикатор «наблюдение идёт».

## Приватность

- `NSLocalNetworkUsageDescription` с честным текстом.
- `NSBonjourServices` со всеми типами из списка. Без этого браузеры молчат на новых версиях macOS.
- Отказ в разрешении: экран с объяснением и кнопкой в системные настройки.

## Границы

- Устройство с двадцатью сервисами: одно устройство, все сервисы в деталях.
- Два устройства с одинаковым именем: разные хосты, два устройства.
- IPv6 только: адрес показывается, копируется.
- Смена сети: список очищается, поиск заново.
- Окно закрыто: браузеры отменены, приложение живёт в доке, повторное открытие запускает заново.

## Не делаем

- Сканирование портов, пинг, ARP.
- Историю, сохранение.
- Уведомления о новых устройствах. Стретч.
- Меню-бар режим. Стретч.
