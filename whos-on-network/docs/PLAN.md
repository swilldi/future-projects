- [ ] Проект macOS, AppKit, без сториборда, sandbox с сетью, plist-ключи.
- [ ] Окно с двумя пустыми панелями.
- [ ] Один `NWBrowser` на `_airplay._tcp`, результаты в консоль. Разрешение появилось.
- [ ] swift-format, `.gitignore`, первый коммит.

Готово, когда в консоли видны Apple TV или колонка.
