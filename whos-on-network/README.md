# Кто в сети

Окно с двумя панелями. Слева устройства, найденные в локальной сети по объявленным сервисам: AirPlay, HomeKit, Companion Link, SMB, SSH, принтеры. У каждого имя, значок по типу, сколько сервисов, когда видели. Справа детали: все сервисы, адреса, TXT-записи. Пассивно, вежливо, без сканирования портов.

## Зачем

Network.framework и Bonjour это редкий и красивый кусок системы, который в приложениях почти не трогают. Здесь он главный: обнаружение сервисов, разрешение адресов, TXT-записи. Плюс ещё один заход в AppKit с двумя панелями и приватность локальной сети, которая с недавних пор спрашивает разрешение и на macOS.

## Что будет в первой версии

- Обнаружение сервисов по списку типов и через мета-запрос всех типов.
- Группировка по хосту: одно устройство, много сервисов.
- Разрешение адресов IPv4 и IPv6 и чтение TXT-записей.
- Список с фильтром, детали с сервисами и записями.
- «Последний раз видели» и исчезновение через таймаут.
- Обновление вручную и непрерывное наблюдение.
- Разрешение на локальную сеть, тексты в Info.plist, состояние «нет доступа».

## Готово, когда

- Все мои устройства Apple в домашней сети видны с правильными именами в течение десяти секунд после запуска.
- Выключенное устройство пропадает из списка в течение минуты.
- Логика слияния сервисов в устройства и истечения покрыта тестами.
- Без разрешения на локальную сеть показывается объяснение, а не пустой список.
- Instruments: браузеры отменяются при закрытии окна, утечек нет.

## Что хочу попробовать

`NWBrowser` с дескриптором Bonjour, мета-запрос типов сервисов, `NWConnection` для разрешения адресов, разбор TXT, `NSSplitViewController` с двумя панелями, `NSOutlineView` или `NSTableView` с группами, приватность локальной сети на macOS, `NSLocalNetworkUsageDescription` и `NSBonjourServices`.
