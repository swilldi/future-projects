# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Движок

- [ ] `ConversionEngine` без зависимостей, на `Decimal`.
- [ ] Ошибка на отсутствующий курс, не ноль и не краш.
- [ ] Округление только на выводе, банковское.

## Границы

- [ ] Сеть только за `RatesClient`, клиент принимает `URLSessionConfiguration`.
- [ ] Часы в репозитории подменяемы.
- [ ] Локаль в ViewModel из init.
- [ ] Аргументы запуска читаются в одном файле.
- [ ] Дублёры в тестовых таргетах, кроме `FixtureRatesClient`.

## Тестовая дисциплина

- [ ] В фазах 1 и 2 тесты появляются в коммитах раньше кода.
- [ ] Юниты на Swift Testing, UI и замеры на XCTest.
- [ ] Снапшоты закреплены за одним устройством, эталоны в репозитории.
- [ ] UI-тесты используют `waitForExistence`, не `sleep`.
- [ ] Идентификаторы доступности на всех интерактивных элементах.
- [ ] Ни один тест не ходит в сеть.

## Доступность

- [ ] Поле, пикеры и результат читаются VoiceOver осмысленно.
- [ ] Dynamic Type до самого большого без обрезания, снапшот есть.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.
