# Спецификация

## Одним абзацем

Один экран. Поле суммы, две валюты, результат. Курсы загружаются с сервера, кэшируются с датой, без сети показываются из кэша с пометкой «курсы от такого-то числа». Всё остальное в этом проекте про тесты.

## Экран

- Поле суммы: числовая клавиатура, разделитель по локали, пусто означает ноль.
- Выбор валюты «из» и «в»: список из тридцати основных валют с кодом и названием.
- Результат: сумма в валюте «в», два знака после запятой, разделители разрядов по локали.
- Кнопка «поменять местами».
- Строка «Курсы от 16.09.2026» и кнопка обновить. Если курсы не загружены и кэша нет: «Курсы недоступны», конвертация не работает.
- Состояния: загрузка курсов, ошибка сети с кэшем, ошибка сети без кэша.

## Логика конвертации

- Курсы приходят относительно EUR. Конвертация из A в B: `amount / rate[A] * rate[B]`, где `rate[EUR] = 1`.
- Все вычисления на `Decimal`. Округление банковское до двух знаков только на выводе.
- Одинаковые валюты: результат равен сумме.
- Нет курса для валюты: ошибка «курс недоступен», не ноль.

## Данные

Источник: frankfurter.app, курсы Европейского центробанка, без ключа:

```
https://api.frankfurter.app/latest?from=EUR
```

Ответ: `{ "base": "EUR", "date": "2026-09-16", "rates": { "USD": 1.08, ... } }`.

Запасной источник: open.er-api.com, тот же смысл, другой формат. В тестах фикстура с двадцатью валютами, записанная в файл.

Кэш: последний ответ в JSON-файле в Caches вместе с датой курсов и датой загрузки. Обновление при запуске, если загрузке больше суток, и по кнопке.

## Аргументы запуска для UI-тестов

- `-uiTesting`: курсы из встроенной фикстуры, сеть не трогается, кэш не читается и не пишется.
- `-uiTestingNoRates`: состояние «курсы недоступны».

## Границы

- Ввод «1,5» и «1.5» оба означают полтора.
- Очень большая сумма: до 15 знаков, дальше поле не принимает.
- Буквы в поле не вводятся.
- Курс отсутствует для выбранной валюты: сообщение вместо результата.
- Повреждённый кэш: как будто его нет.

## Не делаем

- Историю курсов, графики.
- Больше двух валют одновременно.
- Локализацию сверх форматирования чисел по локали.
- Валюты без двух знаков (JPY, KWD) обрабатываем как обычные. Записано как известное упрощение.

## Сущности

```
Rates
  base: String
  date: Date            // дата курсов
  fetchedAt: Date
  values: [String: Decimal]

Currency
  code: String
  name: String

Conversion
  amount: Decimal
  from: Currency
  to: Currency
  result: Decimal
```
