# Конвертер валют: тестовый стенд

Два поля, две валюты, курсы с сервера. Приложение нарочно скучное, чтобы всё внимание ушло на тесты: юнит, интеграционные через подмену сети, снапшоты, UI-тесты, замер производительности и CI, который гоняет всё на каждый пуш.

## Зачем

Научиться писать код, который тестируется без боли, а не дописывать тесты потом. Разобраться в видах тестовых дублёров и понять, какой тест что ловит. Впервые поднять GitHub Actions для iOS-проекта и увидеть зелёную галочку.

## Что будет в первой версии

- Поле суммы, выбор валюты «из» и «в», результат, кнопка поменять местами.
- Курсы с frankfurter.app, кэш последних курсов с датой, работа без сети на кэше.
- Юнит-тесты логики конвертации через Swift Testing, написанные до кода.
- Интеграционные тесты сетевого слоя через `URLProtocol`.
- Снапшот-тесты экрана в трёх состояниях.
- UI-тесты сценария «ввёл, выбрал, увидел» на подменённых курсах.
- Замер производительности конвертации.
- GitHub Actions: форматирование, сборка, все тесты.

## Готово, когда

- Все виды тестов есть и зелёные локально и в CI.
- Покрытие логики конвертации и репозитория курсов 100 процентов, интерфейса сколько получится, и это записано.
- Намеренно сломанная логика конвертации роняет хотя бы один юнит-тест. Проверено руками.
- UI-тест проходит десять раз подряд без падений.
- В `docs/NOTES.md` таблица: вид теста, сколько написано, сколько времени заняло, что поймал.

## Что хочу попробовать

Swift Testing всерьёз: параметризованные тесты, `confirmation`, теги. XCTest там, где Swift Testing не умеет: UI-тесты и `measure`. Подмена сети через `URLProtocol`. Снапшоты через swift-snapshot-testing. Аргументы запуска для детерминированных UI-тестов. GitHub Actions на macOS-раннере. `Decimal` вместо `Double` для денег.

## Как начать

1. Прочитать `docs/SPEC.md` и `docs/ARCHITECTURE.md`.
2. Пробежать `docs/STACK.md`. Раздел «что почитать» смотреть перед соответствующей фазой, не всё сразу.
3. Открыть `docs/PLAN.md` и идти по фазам, отмечая чекбоксы. Агента звать только там, где стоит 🤖.
4. Заметки, решения и вопросы складывать в `docs/NOTES.md`.
