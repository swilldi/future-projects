# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Всё из `go-url-shortener` | Скелет | Что реально переиспользуется |
| Триггеры Postgres, последовательности | Ревизия | `BEFORE INSERT OR UPDATE`, `nextval`, порядок фиксации |
| `ON CONFLICT DO UPDATE ... WHERE` | Идемпотентный импорт | Условный upsert, подсчёт вставок и обновлений |
| `pg_advisory_lock` | Монотонность | Блокировка на запись, где брать и отпускать |
| ETag, `If-None-Match`, `Cache-Control` | Кэширование | Сильный и слабый ETag, 304, что кэшируют промежуточные |
| `crypto/subtle` | Токен | Сравнение постоянного времени, почему `==` опасен |
| Ограничение частоты в памяти | Защита | Счётчики с истечением, `x/time/rate` или свой |
| GRDB в календаре | Локальные факты | Из музея хранилищ |
| `Task` при запуске в SwiftUI | Фоновый синк | Не блокировать первый экран |

## Чего нет и почему

- Пользователей и OAuth. Один администратор.
- Кэша в памяти на сервере. Postgres с индексом достаточно.
