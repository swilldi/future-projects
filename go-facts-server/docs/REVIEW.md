# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `go vet` и `golangci-lint` чисты.
- [ ] `go test -race ./...` зелёный.
- [ ] Образ собирается, `docker compose up` поднимает всё одной командой.

## Ревизии

- [ ] Ревизия только триггером, в Go нет присвоения.
- [ ] Удаление надгробием, физического нет.
- [ ] Монотонность под параллельной записью, тест есть, блокировка на месте.

## Импорт

- [ ] Условный upsert, повторный импорт даёт ноль обновлений.
- [ ] Транзакция, отчёт по счётчикам.

## HTTP

- [ ] ETag из ревизии и количества, 304 без тела, `Cache-Control` на чтение.
- [ ] Дельта с `hasMore`, порядок по ревизии, `since` больше текущей даёт пусто.
- [ ] Неверная дата 400.

## Защита

- [ ] `subtle.ConstantTimeCompare`, лимит попыток, 503 без токена.
- [ ] Токен не в логах.

## Скелет

- [ ] Всё из сокращалки: домен без HTTP и Postgres, обработчики без Postgres, контекст, параметры, `-race`.

## Клиент

- [ ] `FactRepository` календаря не изменён.
- [ ] Слияние идемпотентно по `id` и ревизии, в транзакции на страницу, ревизия после страницы.
- [ ] Синк не блокирует первый экран, ошибка сети молчалива.
- [ ] Бандл как запасной при пустой базе.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Производительность на миллионе фактов, многопользовательскую запись, локализацию.
