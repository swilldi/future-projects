# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `ruff check` и `ruff format --check` чисты.
- [ ] `pytest` зелёный без сети.

## Чистота

- [ ] `parse`, `clean`, `filters`, `select` без сети и файлов.
- [ ] Типы на всех функциях, `mypy` чист.
- [ ] Стоп-слова и пороги в одном месте.

## Сеть и кэш

- [ ] `User-Agent` с контактом, пауза не меньше секунды, повтор на 429 и 5xx.
- [ ] Кэш читается до сети, повреждённый файл не роняет.
- [ ] Прерывание не теряет уже скачанное.

## Отбор и вывод

- [ ] Выбор детерминирован: два прогона дают одинаковый файл.
- [ ] Схема проверяется до записи, запись атомарная.
- [ ] Метаданные с источником и лицензией присутствуют.
- [ ] Статистика печатает пустые дни.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Качество фактов по смыслу: это читается глазами выборочно.
