# Спецификация

## Одним абзацем

Консольная команда `facts-collector` с флагами. По умолчанию обходит все дни, берёт факты, пишет `facts.json` и печатает статистику. Кэширует сырые ответы в `cache/`, чтобы повторные прогоны и отладка фильтров не били по Википедии.

## Источник

Русская Википедия, страницы дней вида `3 сентября`. MediaWiki API:

```
https://ru.wikipedia.org/w/api.php?action=parse&page=3_сентября&prop=wikitext&format=json&formatversion=2
```

Из вики-текста берётся раздел `== События ==` до следующего заголовка второго уровня. Внутри строки вида `* [[1939]] — текст` или `* 1939 — текст`. Подразделы третьего уровня внутри «Событий» (например по векам) тоже берутся.

Запасной источник: Wikimedia REST «On this day» для языков, где он есть: `https://api.wikimedia.org/feed/v1/wikipedia/en/onthisday/events/09/03`. Для русского его может не быть, поэтому основной способ через вики-текст. Адаптер источника за интерфейсом, переключается флагом `--source`.

Правила Wikimedia: `User-Agent` с контактом обязателен, не чаще одного запроса в секунду, `Accept-Encoding: gzip`.

## Разбор и чистка

- Год: число в начале строки, возможно в ссылке `[[1939]]`, возможно с «до н. э.». Строки без года пропускаются.
- Текст: всё после тире. Разметка снимается через `mwparserfromhell.strip_code`: ссылки становятся текстом, шаблоны удаляются, курсив и жирный снимаются, сноски `<ref>` удаляются.
- После чистки: схлопнуть пробелы, убрать хвостовые точки-дубли, первая буква заглавная.
- Отбросить, если: длина меньше 40 или больше 200; остались `[[`, `{{`, `<`; текст начинается с «Умер», «Скончал», содержит «погиб» или «казн»; год раньше 1000, чтобы не тащить сомнительные даты. Список стоп-слов в одном месте.

## Отбор

- До `--limit-per-day` фактов на день, по умолчанию 3.
- Детерминированно: `random.Random(f"{monthDay}")` перемешивает кандидатов, берутся первые. Одинаковый вход даёт одинаковый выход.
- Предпочтение: если кандидатов больше лимита, сначала те, у кого длина от 60 до 140, потом остальные.

## Вывод

Схема, которую читает `tearoff-calendar`:

```
{
  "meta": {
    "source": "Википедия, свободная энциклопедия",
    "license": "CC BY-SA 4.0",
    "licenseURL": "https://creativecommons.org/licenses/by-sa/4.0/",
    "generatedAt": "2026-09-17T20:00:00Z"
  },
  "days": {
    "09-03": [
      {
        "id": "09-03-1",
        "monthDay": "09-03",
        "year": 1939,
        "text": "...",
        "source": "Википедия",
        "sourceURL": "https://ru.wikipedia.org/wiki/3_сентября"
      }
    ]
  }
}
```

Перед записью проверка: все 366 ключей присутствуют, даже с пустым списком; `id` уникальны; `text` не пустой. Статистика в консоль: дней всего, дней без фактов и их список, фактов всего, среднее на день.

## Команда

```
facts-collector [--days 09-03,02-29] [--limit-per-day 3] [--out facts.json]
                [--lang ru] [--source wikitext|feed] [--no-cache] [--cache-dir cache] [-v]
```

Коды выхода: 0 успех, 1 ошибка сети после повторов, 2 невалидный выход.

## Границы

- 29 февраля: страница «29 февраля» существует, обрабатывается как остальные.
- Страница без раздела «События»: день пустой, в статистику.
- Ответ 429: пауза по `Retry-After` или 30 секунд, повтор до трёх раз.
- Кэш повреждён: файл перезапрашивается.
- Ctrl+C посередине: кэш уже скачанных дней сохранён, при повторе продолжается.

## Не делаем

- Другие разделы: «Родились», «Праздники».
- Другие языки сверх флага.
- Дедупликацию похожих фактов.
- Картинки.
