# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Python 3.12, `uv` | Окружение | `uv init`, `uv add`, `uv run`, lock-файл |
| `httpx` | Сеть | Клиент с заголовками, таймауты, коды ответа |
| `mwparserfromhell` | Разметка | `parse`, `strip_code`, фильтры узлов |
| `argparse` | Команда | Подкоманд нет, флаги с типами и значениями по умолчанию |
| `dataclasses`, типы | Модели | `frozen=True`, `Protocol` для источника |
| `pathlib`, `json` | Кэш и вывод | `ensure_ascii=False`, атомарная запись через временный файл |
| `logging` | Прогресс | Уровни, `-v` |
| `pytest` | Тесты | Фикстуры из файлов, параметризация, `tmp_path` |
| `ruff`, `mypy` | Качество | Конфиг в `pyproject.toml` |

## Чего нет и почему

- `requests`: `httpx` современнее и с теми же идеями.
- `click` и `typer`: `argparse` хватает на восемь флагов.
- Асинхронности: один запрос в секунду по правилам, параллелить нечего.
