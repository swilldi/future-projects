# Архитектура

## Коротко

Пакет `facts_collector` с прямолинейным конвейером: источник отдаёт сырой текст дня, парсер превращает в кандидатов, фильтр отбрасывает, селектор выбирает, писатель проверяет и пишет. Каждый шаг это функция. Сеть и диск только в источнике и кэше.

## Почему так

Скрипт на вечер, но с одним требованием: фильтры будут крутиться много раз, и каждый прогон не должен ходить в сеть. Отсюда кэш и чистые функции: сырое скачали один раз, дальше только локально. И тесты на записанных строках, потому что настоящая разметка страшнее любой придуманной.

## Компоненты

**days.all_days().** Список из 366 `MonthDay` с русским названием страницы: `("09-03", "3_сентября")`. Месяцы в родительном падеже в одном словаре.

**http.Client.** Обёртка над `httpx.Client` с заголовками, таймаутом 20 секунд, паузой между запросами через `time.monotonic`, повтором на 429 и 5xx с `Retry-After`. Единственное место, где есть сеть.

**cache.** `get(lang, month_day) -> str | None`, `put(lang, month_day, text)`. Файл на день. Повреждённый файл считается отсутствующим.

**sources.wikitext.** `fetch_day`: кэш, иначе запрос `action=parse`, извлечь `parse.wikitext`, положить в кэш. `feed` аналогично с другим URL и форматом, отдаёт уже готовые строки как псевдо-вики-текст, чтобы дальше конвейер был общий.

**parse.events_section(wikitext) -> list[Candidate].** Найти `== События ==`, взять до следующего `== `, пройти строки на `*`, вытащить год и остаток. Чистая функция.

**clean.clean(raw) -> str.** `mwparserfromhell.parse(raw).strip_code()`, затем нормализация. Чистая.

**filters.is_acceptable(candidate, text) -> bool** и `reason(...)` для статистики отбрасываний. Стоп-слова константой.

**select.pick(month_day, texts, limit) -> list[str].** `random.Random(month_day)`, предпочтение по длине.

**output.write(path, days) и validate(days).** Схема из `SPEC.md`, проверка перед записью, `json.dump` с `ensure_ascii=False` и отступами.

**cli.main.** Разбор флагов, цикл по дням с прогрессом в лог, сбор статистики, коды выхода.

## Поток данных

```
cli ──▶ days.all_days()
    ──▶ для каждого: source.fetch_day ──▶ cache? : http ──▶ cache.put
    ──▶ parse.events_section ──▶ [Candidate]
    ──▶ clean.clean ──▶ filters.is_acceptable ──▶ [text]
    ──▶ select.pick ──▶ [Fact]
    ──▶ output.validate ──▶ output.write ──▶ facts.json
    ──▶ статистика в stdout
```

## Правила

- `parse`, `clean`, `filters`, `select`, `output.validate` не импортируют `httpx` и не открывают файлы.
- Сеть только в `http.py`, диск только в `cache.py` и `output.write`.
- Типы везде, `mypy` без ошибок.
- Стоп-слова и пороги длины в константах одного модуля.
- Тесты не ходят в сеть: фикстуры записаны один раз с флагом `--record`, который есть только в тестовом хелпере.

## Что здесь тестируемо

Весь конвейер после сети: `parse` на записанной странице, `clean` и `filters` на двадцати строках с ожидаемым результатом, `select` на детерминизм и лимит, `output.validate` на все правила схемы. `http` и `cache` покрываются одним тестом с временной папкой.

## Где ожидать боль

- Разметка Википедии разнообразнее, чем кажется: годы в ссылках с подписью `[[1939 год|1939]]`, тире трёх видов, шаблоны дат `{{Дата|...}}`. Записать реальные строки в фикстуры и подгонять `clean` под них.
- `strip_code` иногда оставляет хвосты от шаблонов. Отбрасывать по остаткам разметки, не чинить.
- Раздел может называться «События» с якорем или без, с пробелами. Регулярное выражение с допусками.
- Кодировка URL для русских названий: `httpx` кодирует сам, но название с пробелом должно стать с подчёркиванием.
- 366 запросов по секунде это шесть минут. Кэш делает это однократным.
