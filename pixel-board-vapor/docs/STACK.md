# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Vapor 4 | Сервер | `configure`, маршруты, контроллеры, middleware, окружение, жизненный цикл |
| WebSocket в Vapor | Реальное время | `app.webSocket`, `onText`, `send`, `onClose`, пинг |
| Fluent и FluentPostgresDriver | База | Модели, миграции, пачки, транзакции, `Environment` |
| Акторы на сервере | Состояние | Хаб соединений, рассылка, таймеры через `Task` |
| Общий пакет | Модели | Зависимость двух проектов от одного пакета, ограничения на Linux |
| `URLSessionWebSocketTask` | Клиент | `receive` в цикле, `send`, обрывы, переподключение |
| SwiftUI `Canvas`, жесты | Холст | Масштаб, смещение, перевод координат |
| XCTVapor | Тесты сервера | `app.test`, WebSocket в тестах |
| Docker для Swift | Развёртывание | Образ `swift` для сборки, `slim` для запуска, размер |
| Нагрузка скриптом | Проверка | Сто клиентов, метрики, память сервера |

## Чего нет и почему

- Redis для распределённого состояния. Один сервер.
- Авторизации. Не в объёме.
