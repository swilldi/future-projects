# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `swift build` и `swift test` зелёные на macOS и в Docker на Linux.
- [ ] Без warnings. swift-format ничего не меняет.

## Протокол

- [ ] Сообщения только из `PixelShared`, кодирование покрыто тестами в обе стороны.
- [ ] Валидация координат, цвета, формата на сервере.
- [ ] Мусор и `place` до `hello` закрывают соединение с кодом.

## Акторы

- [ ] Доска, соединения, буфер событий в акторах.
- [ ] Рассылка не блокируется медленным клиентом.
- [ ] Мёртвые соединения удаляются по пингу.
- [ ] Задержка проверяется в хабе по `clientID`.

## База

- [ ] События пачками, снимки раз в минуту, контроллеры базу не трогают.
- [ ] Загрузка при старте из снимка плюс событий.
- [ ] Недоступная база не роняет доску, буфер ограничен.
- [ ] Миграции отдельной командой в compose.

## Клиент

- [ ] Оптимизм с откатом, `pending` очищается на снимке.
- [ ] Переподключение с задержкой и снимком.
- [ ] Соединение в акторе, интерфейс через поток.
- [ ] Адрес сервера настраивается.

## Контейнеры

- [ ] Многоэтапная сборка, образ запуска без компилятора.
- [ ] `compose.yaml` с healthcheck базы и миграциями.

## Нагрузка

- [ ] Сто клиентов десять минут без роста памяти, числа записаны.

## Доступность

- [ ] Палитра с названиями цветов, холст с описанием и альтернативным вводом координат.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, безопасность сверх валидации, масштабирование на несколько серверов.
