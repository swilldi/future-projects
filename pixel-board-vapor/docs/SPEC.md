# Спецификация

## Одним абзацем

Сервер отдаёт снимок доски по HTTP и поток изменений по WebSocket, принимает пиксели с проверкой. Клиент показывает доску, ставит пиксели, живёт при обрывах. Доска 100 на 100, палитра 16 цветов, задержка две секунды на клиента.

## Общий пакет `PixelShared`

```
public enum Palette { static let colors: [UInt8: RGB] }   // 0…15
public struct BoardSize { width: 100, height: 100 }

public enum ClientMessage: Codable {
  case hello(clientID: UUID)
  case place(x: Int, y: Int, color: UInt8)
}

public enum ServerMessage: Codable {
  case snapshot(version: Int, pixels: Data)          // width*height байт, по цвету на пиксель
  case placed(x: Int, y: Int, color: UInt8, version: Int)
  case rejected(reason: RejectReason, retryAfter: Double?)
  case cooldown(seconds: Double)
}

public enum RejectReason: String, Codable { case cooldown, outOfBounds, badColor, badMessage }
```

Кодирование JSON, снимок в `Data` через base64 внутри JSON. Бинарный протокол в стретче.

## Сервер

- `GET /board`: JSON `{ version, width, height, pixels: base64 }`.
- `GET /healthz`.
- `WS /live`: клиент шлёт `hello`, сервер отвечает `snapshot`, дальше рассылает `placed` всем. Клиент шлёт `place`, сервер проверяет и либо рассылает `placed` всем, включая отправителя, либо отвечает `rejected` только ему.
- Задержка: две секунды на `clientID`. Хранится в памяти хаба, сбрасывается при рестарте: принято.
- Версия доски: счётчик, растёт на каждый пиксель. Клиент сравнивает и при разрыве запрашивает снимок.
- Пинг раз в 30 секунд, соединение без ответа два раза закрывается.
- Лимит соединений 1000, дальше отказ с кодом.
- История: таблица `pixel_event` с `x, y, color, client_id, version, created_at`, запись пачками раз в секунду. Таблица `board_snapshot` с `version, pixels, created_at`, запись раз в минуту, если версия изменилась. При старте: последний снимок плюс события после него.
- Конфигурация: `DATABASE_URL`, `PORT`, `COOLDOWN_SECONDS`, `BOARD_SIZE` (пока только 100).

## Клиент

- Холст: сетка пикселей, зум щипком от 1 до 20 крат, панорама.
- Палитра внизу, выбранный цвет.
- Тап по пикселю: оптимистично красим, шлём `place`. `rejected`: откат и подсказка. `placed` с нашими координатами: подтверждение.
- Таймер до следующего пикселя из `cooldown`.
- Подключение при открытии, `hello` с сохранённым `clientID`, снимок, живые обновления.
- Переподключение с задержкой 1, 2, 4, 8 секунд, потом раз в 15. Индикатор «нет связи». После переподключения снимок заново.
- Адрес сервера в настройках, по умолчанию локальный.

## Границы

- Два пикселя в одну клетку одновременно: побеждает тот, кто обработан хабом позже, оба клиента увидят итог.
- Клиент шлёт `place` до `hello`: закрытие с кодом.
- Клиент шлёт мусор: закрытие.
- Сервер перезапущен: клиенты переподключаются, снимок из базы.
- База недоступна при старте: сервер не стартует. База отвалилась во время работы: доска работает из памяти, запись копится в буфере до 10 000 событий, потом старые выбрасываются с логом.
- Сто клиентов ставят пиксели без пауз (нагрузка): задержка отсекает, рассылка справляется.

## Не делаем

- Аккаунты, авторизацию. `clientID` это честное слово.
- Историю в интерфейсе. Стретч: таймлапс.
- Доски больше 100 на 100.
- Модерацию.
