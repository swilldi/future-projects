# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

Отдельное правило этого проекта: отклонение от `ARCHITECTURE.md` это блокер, даже если код от отклонения становится лучше. Полигон сравнивает архитектуры, а не ищет лучший код.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Сервисы

- [ ] `CountriesAPI` передаёт `fields`.
- [ ] `CountryDTO` не утекает на экраны, везде `Country`.
- [ ] Кэш в Caches, избранное в Documents, разные файлы.
- [ ] Повреждённый файл даёт пустое значение, не краш.
- [ ] Сервисы не импортируют UI-фреймворк.

## Архитектура

- [ ] ViewModel без UIKit.
- [ ] Контроллеры без логики, в `sink` только `render`.
- [ ] Одно выходное состояние на экран.
- [ ] `[weak self]` и `cancellables` везде, `Task` для `changes` отменяется в `deinit` или при уходе.
- [ ] `receive(on:)` в контроллере, не в ViewModel.
- [ ] `debounce` на поиске, `removeDuplicates` после него.
- [ ] Тесты ViewModel проверяют состояние, не вызовы.

## Состояния и края

- [ ] Загрузка показывается только когда кэша нет.
- [ ] Ошибка без кэша: экран с повтором. С кэшем: тихий индикатор.
- [ ] Пустой поиск, страна без столицы, несколько столиц, нет валют: по спецификации.
- [ ] Поиск нечувствителен к регистру и диакритике.
- [ ] Избранное меняется во всех экранах сразу.
- [ ] Флаг не загрузился: серый прямоугольник.

## Доступность

- [ ] Ячейка читается VoiceOver как «название, столица».
- [ ] Кнопка избранного с подписью и состоянием.
- [ ] Dynamic Type до самого большого размера без обрезания.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, производительность, локализацию.
