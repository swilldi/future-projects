# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] `go vet` и `golangci-lint` чисты.
- [ ] `go test -race ./...` зелёный.
- [ ] Образ собирается, `docker compose up` поднимает всё одной командой.

## Домен

- [ ] `internal/link` без импортов `net/http`, `database/sql`, `postgres`.
- [ ] `Store` интерфейс в `link`, реализации снаружи.
- [ ] Валидация URL и alias в сервисе, не в обработчиках.
- [ ] Генератор кодов подменяем.

## Ошибки

- [ ] Ошибки домена объявлены как значения, проверяются через `errors.Is`.
- [ ] Обёртки через `%w` с контекстом, без потери причины.
- [ ] Ни одного `panic` вне `main`.
- [ ] Ошибка драйвера `23505` переведена в доменную.

## HTTP

- [ ] Роутинг стандартный с шаблонами, без сторонних роутеров.
- [ ] Каждая ручка отвечает по таблице в `SPEC.md`, включая коды ошибок.
- [ ] Таймауты сервера заданы.
- [ ] Лимит тела, recover, request id, лог запроса в middleware.
- [ ] Обработчики не знают о Postgres.

## База

- [ ] Все запросы с параметрами и контекстом.
- [ ] Инкремент одним `UPDATE`.
- [ ] Пул ограничен.
- [ ] Миграции только добавляются.
- [ ] Интеграционные тесты под тегом, пропускаются без `TEST_DATABASE_URL`.

## Контейнеры

- [ ] Многоэтапная сборка, статический бинарник, не root.
- [ ] `compose.yaml` с healthcheck и условиями `depends_on`.
- [ ] Секреты и `DATABASE_URL` не в образе.

## Завершение и логи

- [ ] Сигналы обработаны, `Shutdown` с таймаутом, база закрывается после сервера.
- [ ] Логи в JSON с request id и длительностью.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Производительность сверх «сто горутин не теряют инкременты», безопасность сверх валидации, UI.
