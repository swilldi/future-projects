# План

Фазы идут по порядку. Каждая заканчивается рабочим состоянием и коммитом. «Вопросы себе» это то, на что я должен уметь ответить после фазы, не заглядывая в документацию. Не могу ответить, значит фаза не закончена.

Где звать агента, отмечено значком 🤖. В остальных местах не звать.

## Фаза 0. Модуль, здоровье, контейнер

Цель: сервис отвечает на `/healthz` локально и из контейнера.

- [ ] `go mod init`, `cmd/shortener/main.go` с `/healthz`.
- [ ] `config.Load` с `PORT`.
- [ ] `Dockerfile` многоэтапный, образ собирается, контейнер отвечает.
- [ ] `compose.yaml` с `app` и `db`, пока без миграций.
- [ ] `Makefile`, `.golangci.yml`, `.gitignore`, первый коммит.

Вопросы себе: что такое модуль и чем отличается от пакета? Почему `internal`? Что делает `CGO_ENABLED=0`?

Готово, когда `docker compose up` отвечает на `curl localhost:8080/healthz`.

- [ ] `Link`, ошибки, интерфейс `Store`, `CodeGenerator`.
- [ ] `memstore` с мьютексом.
- [ ] `Service`: `Create`, `Resolve`, `Stats`, `List`, `Delete`.
- [ ] Табличные тесты валидации URL и alias.
- [ ] Тест коллизий с генератором, который возвращает один код дважды.
- [ ] Тест `memstore` на сто горутин, запуск с `-race`.

Вопросы себе: почему интерфейс `Store` лежит в `link`, а не в `postgres`? Чем `errors.Is` отличается от сравнения? Зачем `sync.RWMutex`, а не `sync.Mutex`?

Готово, когда `go test -race ./internal/link/... ./internal/memstore/...` зелёный.

## Фаза 3. Postgres

Цель: настоящее хранилище с миграциями.

- [ ] Миграция `0001_links.sql`: таблица, уникальный индекс на код.
- [ ] `postgres.Migrate` из `embed.FS`.
- [ ] `postgres.Store`, все методы, перевод `23505` в `ErrAliasTaken`.
- [ ] Интеграционные тесты под тегом: те же сценарии, что у `memstore`, плюс сто горутин на `IncrementClicks`.
- [ ] `main` подключает базу, `SetMaxOpenConns`.

Вопросы себе: почему инкремент одним `UPDATE`, а не чтение плюс запись? Что произойдёт при отмене контекста посреди запроса? Что такое `sql.ErrNoRows`?

Готово, когда интеграционные тесты зелёные против Postgres в Docker.

🤖 Ревью. Раздел «База».
