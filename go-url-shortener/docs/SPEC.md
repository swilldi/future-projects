# Спецификация

## Одним абзацем

HTTP-сервис на порту из `PORT`. Принимает длинную ссылку, отдаёт код. По коду редиректит и считает. Отдаёт статистику и список. Без авторизации: это учебный сервис, и это записано как известное ограничение.

## API

| Метод и путь | Тело или параметры | Ответ | Ошибки |
|---|---|---|---|
| `POST /api/links` | `{"url": "https://...", "alias": "необязательно"}` | `201 {"code","short_url","url","created_at"}` | 400 невалидный URL или alias, 409 alias занят |
| `GET /{code}` | | `302 Location: url`, счётчик +1 | 404 |
| `GET /api/links/{code}` | | `200 {"code","url","created_at","clicks"}` | 404 |
| `GET /api/links` | `?limit=100` | `200 {"items":[...]}`, по дате создания, новые сверху | |
| `DELETE /api/links/{code}` | | `204` | 404 |
| `GET /healthz` | | `200 {"status":"ok","db":"ok"}` | 503 если база недоступна |

Ошибки в JSON: `{"error": {"code": "invalid_url", "message": "..."}}`. Коды ошибок: `invalid_url`, `invalid_alias`, `alias_taken`, `not_found`, `internal`.

## Правила

- URL: схема `http` или `https`, есть хост, длина до 2048. Иначе 400.
- Код: семь символов из `[a-zA-Z0-9]`, случайный из `crypto/rand`. Коллизия: повтор до пяти раз, потом 500.
- Alias: от 3 до 32 символов из `[a-zA-Z0-9_-]`, регистр важен. Не может совпадать с `api`, `healthz`.
- Редирект `302`, не `301`: браузер не должен кэшировать, иначе счётчик не растёт.
- Счётчик: `UPDATE links SET clicks = clicks + 1 WHERE code = $1` одним запросом, без чтения перед записью.
- Удалённая ссылка: 404 на всё, код не переиспользуется.

## Конфигурация

Переменные окружения: `PORT` (по умолчанию 8080), `DATABASE_URL` (обязательна), `BASE_URL` для `short_url` (по умолчанию `http://localhost:PORT`), `LOG_LEVEL` (`info`). Отсутствие обязательной переменной: сервис не стартует с понятным сообщением.

## Завершение

`SIGINT` и `SIGTERM`: перестать принимать соединения, дождаться текущих до 10 секунд, закрыть базу, выйти с нулём.

## Логи

`slog` в JSON. На каждый запрос: метод, путь, статус, длительность, идентификатор запроса из заголовка `X-Request-ID` или сгенерированный. Ошибки с полем `err`.

## Docker

- `Dockerfile`: этап сборки на образе `golang`, этап запуска на `gcr.io/distroless/static` или `scratch`, статический бинарник, пользователь не root.
- `compose.yaml`: `db` (postgres с healthcheck), `migrate` (тот же образ, команда `migrate up`, зависит от здоровой базы), `app` (зависит от завершения миграций).
- Одна команда: `docker compose up --build`.

## Границы

- Alias совпадает со случайно сгенерированным кодом другой ссылки: уникальность на уровне базы.
- Два одинаковых URL: две разные ссылки, дедупликации нет.
- База упала во время работы: `healthz` 503, остальные 500 с `internal`, сервис не падает.
- Тело запроса больше 1 мегабайта: 413.
- Сто параллельных редиректов по одному коду: счётчик ровно сто.

## Не делаем

- Авторизацию, пользователей.
- Срок жизни ссылок.
- Ограничение частоты. Стретч.
- Кэш в памяти.
- Кастомные домены.

## Сущности

```
Link
  Code      string
  URL       string
  CreatedAt time.Time
  Clicks    int64

Store (интерфейс)
  Create(ctx, link) error            // ErrAliasTaken при конфликте
  Get(ctx, code) (Link, error)       // ErrNotFound
  List(ctx, limit) ([]Link, error)
  Delete(ctx, code) error            // ErrNotFound
  IncrementClicks(ctx, code) error   // ErrNotFound
  Ping(ctx) error
```
