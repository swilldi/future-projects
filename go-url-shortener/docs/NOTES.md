# Заметки

## Скелет для следующих

Раскладка `cmd`, `internal/{config,server,postgres}`, `Dockerfile`, `compose.yaml`, `Makefile` и CI переезжают в `go-facts-server` как есть. Записывать сюда, что бы поменял во второй раз.

## Решения

- 2026-09-17. Заготовка создана.
- 2026-09-17. Роутер стандартный, без chi и gin.
- 2026-09-17. `database/sql` через `pgx/stdlib`, не нативный API pgx, чтобы увидеть стандартный интерфейс.
- 2026-09-17. Миграции отдельным сервисом compose, не при старте приложения.
