# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Модель

- [ ] Связи и правила удаления как в `SPEC.md`.
- [ ] Версия модели для миграции добавлена, старая не тронута.
- [ ] Ручной чистки связей нет.

## Контексты

- [ ] Импорт в фоновом контексте пачками, `viewContext` сливает автоматически.
- [ ] `NSManagedObject` не покидает `Persistence/` и вью с `@FetchRequest`.
- [ ] `Rules/` и `Export/` без `import CoreData`.

## Мутации и отмена

- [ ] Все мутации через `RosterService`, из вью прямых изменений нет.
- [ ] Каждая мутация в группе отмены с названием.
- [ ] Перестановка пересчитывает `order` в одной группе.
- [ ] Заморозка имени и очков при создании юнита.

## Правила

- [ ] Тесты на каждое предупреждение и на ограничения опций.
- [ ] Расчёт очков над снимком.

## Экспорт

- [ ] JSON круговой тест.
- [ ] PDF пагинируется, не обрезает.
- [ ] Импорт битого JSON не трогает базу.

## Доступность

- [ ] Три колонки навигируются VoiceOver, юниты читаются с очками.
- [ ] Перетаскивание имеет альтернативу: действия «вверх» и «вниз».

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.
