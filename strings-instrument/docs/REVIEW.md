# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Границы пакетов

- [ ] `StringsCore` без UIKit, AVFoundation, Metal, CoreHaptics.
- [ ] `StringsAudio` и `StringsRender` не импортируют друг друга.
- [ ] `Instrument` единственная точка, где встречаются подсистемы.
- [ ] Пресеты как данные, ветвления по `preset.id` нет.

## Физика и состояние

- [ ] Фиксированный подшаг, не зависящий от частоты кадров.
- [ ] Тесты на энергию, закреплённый узел, симметрию срыва.
- [ ] `PlayState` покрыт таблицей переходов, нет состояния, из которого нет выхода.
- [ ] Пороги в одном файле констант.

## Ввод

- [ ] Только `TouchInputView`, `DragGesture` для струн отсутствует.
- [ ] `touchesCancelled` обработан: струна отпускается без звука.
- [ ] Ладонь отфильтрована по радиусу и плотности, тест на записанном сценарии.
- [ ] Захват следующей струны тем же пальцем работает по пересечению.
- [ ] Два пальца на одной струне: второй игнорируется.

## Кадр

- [ ] `tick` без аллокаций, `StringsFrame` переиспользуется.
- [ ] Кадр в 8 мс при пяти пальцах и тяжёлом пресете, замер записан.
- [ ] Рендерер не знает о физике, читает только `StringsFrame`.

## Аудиопоток

- [ ] Все пункты раздела «Реальное время» из `string-audio-sandbox/docs/REVIEW.md`.
- [ ] 16 голосов, вытеснение самого тихого.
- [ ] Эффекты без аллокаций, буферы эха выделены заранее.
- [ ] Подложка не мешает задержке инструмента.

## Отклик

- [ ] Транзиент по силе, движок перезапускается после сброса.
- [ ] Запасной вариант без CoreHaptics.
- [ ] Отклик не блокирует главный поток.

## Жизненный цикл

- [ ] Прерывание, маршрут, фон: движок и отклик восстанавливаются.
- [ ] Настройки сохраняются и применяются при старте.
- [ ] Поворот iPad не роняет буферы.

## Доступность

- [ ] Настройки читаются VoiceOver, все элементы с подписями.
- [ ] «Уменьшение движения»: волна в покое и частицы спокойнее.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Красоту тембров сверх «узнаваемо», дизайн частиц, локализацию.
