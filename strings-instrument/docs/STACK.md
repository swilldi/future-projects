# Стек

Версии на момент написания, сентябрь 2026. При старте проверить и поправить.

## Основа

| Что | Зачем здесь | Что хочу понять |
|---|---|---|
| Swift 6, четыре локальных пакета | Границы подсистем | Как пакеты навязывают направление зависимостей |
| SwiftUI | Настройки, обёртка | `UIViewRepresentable` с двумя UIView в одном контейнере |
| UIKit `touchesBegan` и родственники | Мультитач | `isMultipleTouchEnabled`, `majorRadius`, `touchesCancelled`, координаты относительно вью |
| AVAudioEngine, AVAudioSourceNode | Звук | Из песочницы, плюс второй узел для подложки и смешивание |
| Карплус-Стронг с фильтрами, перегруз, эхо | Тембры | Что даёт фильтр в петле, как звучит мягкое ограничение, что такое эхо с обратной связью |
| Metal | Струны и частицы | Из песочницы, плюс вспышки и цвет по пресету |
| Конечные разности для волнового уравнения | Физика струн | Устойчивость шага, затухание, закреплённые узлы |
| CoreHaptics | Отдача в палец | `CHHapticEngine`, транзиентные события, интенсивность и резкость, перезапуск |
| `CADisplayLink` или колбэк `MTKView` | Такт кадра | Один источник времени для физики и рендера |
| Instruments: Time Profiler, Allocations, Metal System Trace | Целое приложение | Где уходит кадр, кто аллоцирует, как аудио и рендер делят процессор |

## Чего нет и почему

- Сторонних аудио и графических библиотек. Обе подсистемы уже написаны в песочницах.
- Сэмплов инструментов в первой версии. Решение записано в `NOTES.md` и может быть пересмотрено.
- SwiftUI-жестов для струн. Не дают мультитач.
