# Спецификация

## Одним абзацем

Один экран, `MTKView` во весь размер, поверх полупрозрачная панель слайдеров и счётчик кадров. Линии колышутся, частицы летят, касание даёт рябь. Ни одного `UIView` сверх панели управления.

## Сцена

### Линии

- Восемь горизонтальных линий, равномерно по высоте с отступами.
- Форма каждой: сумма трёх синусоид с разными частотами и фазами, смещёнными по номеру линии, плюс время. Параметры: амплитуда, скорость.
- Толщина от 2 до 8 точек, с учётом масштаба экрана.
- Цвет один, с лёгким свечением по краям через фрагментный шейдер.
- Рябь от касания: гауссов бугор с центром в точке касания на ближайшей линии, амплитуда затухает за секунду.

### Частицы

- Количество от 100 до 5000, слайдер.
- Стили: искры (летят вверх, гаснут, оранжевые), дождь (падают, тонкие, синие), звёзды (мерцают на месте, белые).
- Каждая частица: позиция, скорость, возраст, размер. Обновление на CPU в первой версии, на GPU в стретче.
- Частица, вышедшая за экран или состарившаяся, возрождается с новыми параметрами.
- Рисуются инстансингом: один квадрат, N экземпляров, размер и цвет из буфера экземпляров.

### Панель

- Слайдеры: амплитуда, скорость, толщина, число частиц. Пикер стиля.
- Счётчик: кадры в секунду за последнюю секунду, время кадра GPU в миллисекундах.
- Кнопка «скрыть панель».

## Рендер

- `MTKView` с `preferredFramesPerSecond = 120`, `colorPixelFormat = .bgra8Unorm`, MSAA 4x.
- Два конвейера: линии и частицы. Один проход рендера, два вызова `draw`.
- Линии как полоса треугольников: для каждой линии N сегментов, для каждого две вершины по нормали. В первой версии вершины считает CPU и пишет в буфер. Во второй версии в буфере только параметры, вершинный шейдер считает форму сам по `vertex_id`.
- Юниформы: время, размер экрана, амплитуда, скорость, толщина, до четырёх точек ряби с временем начала.
- Тройная буферизация: три набора буферов юниформов и инстансов, семафор на три, ожидание в начале `draw`, сигнал в `addCompletedHandler`.

## Границы

- Частиц 0: конвейер частиц пропускается, не падает.
- Устройство без ProMotion: 60 кадров, счётчик показывает 60.
- Уход в фон: `MTKView` останавливается через `isPaused`, при возврате продолжает без скачка времени.
- Поворот экрана: буферы не пересоздаются, юниформы обновляются.
- Пять касаний одновременно: рябь на четырёх, пятое игнорируется.

## Не делаем

- Текстуры, картинки.
- Физику струн. Это «Струны».
- Пост-обработку, блум по-настоящему. Свечение только в фрагментном шейдере.
