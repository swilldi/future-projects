# Заметки

## Для чего числа

Таблица из фазы 7 идёт в `strings-instrument/docs/NOTES.md`. По ней решается, сколько частиц могут себе позволить пресеты «Струн».

## Решения

- 2026-09-17. Заготовка создана.
- 2026-09-17. `DispatchSemaphore` для кадров в полёте разрешён как единственное исключение.
- 2026-09-17. Сначала волна на CPU, потом в шейдере: чтобы увидеть разницу числами.
- 2026-09-17. Без текстур в первой версии.
## Открытые вопросы

- Толстые линии: miter или отдельные квадраты на сегмент? Начать с miter.
- Порядок рисования частиц при альфа-смешивании: сортировать или смириться?

## Идеи на потом

- Вычислительный шейдер для частиц.
- Тот же рендерер как пакет для «Струн»: линии как есть, физика снаружи.
