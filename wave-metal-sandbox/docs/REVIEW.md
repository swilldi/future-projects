# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Структуры и буферы

- [ ] Все структуры для GPU из `ShaderTypes.h`, в Swift нет их копий.
- [ ] Буферы под максимум, выделены в init.
- [ ] Запись в буферы через `contents()` и `memcpy` или прямую запись, без промежуточных массивов.
- [ ] Индексы буферов в шейдере и в энкодере совпадают, вынесены в константы заголовка.

## Кадры в полёте

- [ ] Семафор на три, `wait` до записи, `signal` в обработчике завершения.
- [ ] Индекс набора по кругу, набор не переиспользуется до сигнала.
- [ ] В `draw(in:)` нет аллокаций, проверено Instruments.

## Рендер

- [ ] MSAA согласован между вью, конвейерами и проходом.
- [ ] `preferredFramesPerSecond` 120 и ключ в Info.plist.
- [ ] `isPaused` при уходе в фон, время не прыгает при возврате.
- [ ] Нулевое количество частиц не роняет.
- [ ] Шейдеры из `.metal`, не из строк.

## Симуляция

- [ ] `Simulation/` без Metal.
- [ ] Тесты волны и частиц зелёные.
- [ ] Шейдерная волна совпадает с CPU-эталоном визуально, записано.

## Доступность

- [ ] Панель управления читается VoiceOver.
- [ ] «Уменьшение движения»: амплитуда и частицы снижаются.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, красоту эффектов, поведение на старых устройствах без ProMotion сверх 60 кадров.
