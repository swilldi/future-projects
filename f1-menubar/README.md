# F1 в менюбаре

В строке меню живёт надпись вроде «Q через 2ч 15м» или «🏁 вс 15:00». Клик открывает меню: все сессии ближайшего уикенда в местном времени, тройка последней гонки, настройки, выход. За десять минут до сессии приходит уведомление. Без иконки в доке, с автозапуском при входе.

## Зачем

AppKit живьём на задаче, которая реально пригодится. Менюбар-утилиты это чисто macOS-жанр: `NSStatusItem`, меню кодом, окно настроек, автозапуск, поведение при сне. И первый потребитель собственного пакета: сразу видно, чего в его API не хватает.

## Что будет в первой версии

- Пункт в строке меню с текстом отсчёта, обновляется раз в минуту.
- Меню: уикенд с сессиями в местном времени, тройка последней гонки, обновить, настройки, выход.
- Расписание через F1Kit, кэш на диске, обновление раз в сутки и после пробуждения.
- Уведомление за N минут до сессии, N из настроек, для всех сессий или только гонки.
- Окно настроек: N, только гонка, автозапуск, показывать иконку вместо текста.
- Без иконки в доке. Автозапуск через `SMAppService`.
- Офлайн: показывать из кэша, «—» если кэша нет.

## Готово, когда

- Утилита живёт в менюбаре неделю без перезапуска: после сна, смены сети, ночи.
- Уведомление пришло перед реальной сессией.
- Автозапуск включается и выключается из настроек, проверено перезагрузкой.
- Без сети показывает кэш и не спамит запросами.
- Текст в строке меню не длиннее 16 символов.
- В `docs/NOTES.md` список того, чего не хватило в F1Kit, как запрос на версию 0.2.

## Как начать

1. Прочитать `docs/SPEC.md` и `docs/ARCHITECTURE.md`.
2. Пробежать `docs/STACK.md`. Раздел «что почитать» смотреть перед соответствующей фазой, не всё сразу.
3. Открыть `docs/PLAN.md` и идти по фазам, отмечая чекбоксы. Агента звать только там, где стоит 🤖.
4. Заметки, решения и вопросы складывать в `docs/NOTES.md`.
