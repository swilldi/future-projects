# Спецификация

## Одним абзацем

Приложение без окна и без иконки в доке. Пункт в строке меню, меню по клику, окно настроек по пункту. Раз в сутки и при пробуждении обновляет расписание, раз в минуту обновляет текст, за N минут до сессии присылает уведомление.

## Строка меню

- Текст: до следующей сессии больше суток: `🏁 вс 15:00` для гонки, `Q сб 17:00` для квалификации, с днём недели. Меньше суток: `Q через 2ч 15м`. Меньше часа: `Q через 42м`. Идёт сейчас: `Q идёт`. Сезон окончен: `F1`.
- Сокращения: `FP1`, `FP2`, `FP3`, `SQ`, `Спринт`, `Q`, `🏁`.
- Настройка «иконка вместо текста»: только флаг, текст в подсказке.
- Максимум 16 символов, иначе обрезка с многоточием.

## Меню

1. Заголовок уикенда: «Гран-при Италии, Монца» неактивный.
2. Сессии уикенда по порядку: «Пт 13:30 FP1», прошедшие серым, ближайшая жирным.
3. Разделитель.
4. «Последняя гонка: Гран-при Нидерландов» и три строки с позицией, пилотом, командой.
5. Разделитель.
6. «Обновить» с временем последнего обновления в подсказке.
7. «Настройки…» ⌘,
8. «Выйти» ⌘Q

Меню собирается при каждом открытии из текущей модели.

## Настройки

Окно на SwiftUI внутри `NSHostingController`, одно, повторный вызов показывает существующее.

- Напоминать за: 5, 10, 15, 30, 60 минут.
- Только перед гонкой: переключатель.
- Запускать при входе: переключатель, `SMAppService`.
- Иконка вместо текста: переключатель.
- Сезон: текущий год, можно выбрать прошлый для проверки.
- Версия, ссылка на источник данных.

## Данные и обновление

- Расписание сезона и результаты последней завершённой гонки через F1Kit.
- Кэш: JSON в Application Support, с датой загрузки.
- Обновление: при старте, если кэшу больше часа; раз в сутки в 04:00 местного; после пробуждения, если кэшу больше часа; по кнопке.
- Результаты последней гонки: обновляются вместе с расписанием и дополнительно через два часа после окончания гонки.
- Ошибка сети: кэш остаётся, в меню строка «Не удалось обновить» серым, повтор через час.

## Уведомления

- Разрешение запрашивается при первом включении напоминаний, не при старте.
- На каждую будущую сессию уикенда (или только гонку) планируется уведомление за N минут: «Квалификация через 10 минут. Монца».
- Идентификатор `season-round-kind`. Перепланирование удаляет старые с теми же идентификаторами и ставит новые.
- Клик по уведомлению открывает меню? На macOS нельзя; просто ничего.

## Жизненный цикл

- `LSUIElement` в Info.plist.
- Сон и пробуждение через `NSWorkspace.didWakeNotification`.
- Смена часового пояса: тексты пересчитываются.
- Выход по ⌘Q из меню.

## Границы

- Сезон окончен: текст `F1`, в меню «Сезон окончен», уведомлений нет.
- Кэша нет и сети нет: текст `—`, в меню «Нет данных».
- Сессия идёт прямо сейчас: «идёт» в течение двух часов от старта.
- Компьютер спал две недели: после пробуждения обновление, перепланирование уведомлений.
- Пользователь отозвал разрешение на уведомления: тумблер в настройках отражает, планирование молча не делается.

## Не делаем

- Живой тайминг, позиции по ходу гонки.
- Несколько серий.
- Виджет.
- Локализацию сверх русского.
