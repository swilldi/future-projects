# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Чистые компоненты

- [ ] `StatusTextFormatter`, `MenuBuilder`, `RefreshScheduler` без AppKit и сети, время параметром.
- [ ] Тесты форматтера на каждое правило из `SPEC.md`, включая обрезку до 16 символов.
- [ ] Тесты меню на пустые состояния.

## Строка меню

- [ ] Меню собирается в `menuWillOpen`, без сети внутри.
- [ ] Тикер попадает на границу минуты и сбрасывается после пробуждения.
- [ ] Текст обновляется только по тику и по изменению состояния.

## Данные

- [ ] F1Kit единственный источник, прямых запросов нет.
- [ ] Сеть только из `ScheduleModel` по расписанию из `RefreshScheduler`.
- [ ] Ошибка сети не затирает кэш.
- [ ] Кэш в Application Support.

## Уведомления

- [ ] Только `NotificationPlanner` трогает центр.
- [ ] Идентификаторы `season-round-kind`, перепланирование без дублей.
- [ ] Разрешение по действию, не при старте.
- [ ] «Только гонка» уважается.

## Жизненный цикл

- [ ] `LSUIElement`, sandbox с сетью.
- [ ] Пробуждение обрабатывается: тикер, обновление, уведомления.
- [ ] Смена часового пояса обрабатывается.
- [ ] Окно настроек одно, активируется поверх.
- [ ] `SMAppService` статус отражён в настройках.

## Доступность

- [ ] Пункт в менюбаре с `accessibilityLabel`, полный текст в подсказке при иконке.
- [ ] Настройки читаются VoiceOver.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, локализацию, поведение при нескольких мониторах.
