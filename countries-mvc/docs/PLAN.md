## Фаза 0. Каркас

Цель: пустой проект, который собирается.

- [ ] iOS App, жизненный цикл через App Delegate и Scene Delegate, программный UI: убрать сториборд из Info.plist, окно создаёт `SceneDelegate`.
- [ ] `.swift-format` в корне, `.gitignore` для Xcode, первый коммит.
- [ ] Папки из `ARCHITECTURE.md` созданы, пустые файлы допустимы.
- [ ] `SceneDelegate` собирает `UITabBarController` с двумя `UINavigationController`.
- [ ] `AppDependencies` с тремя сервисами.

Готово, когда приложение запускается с пустым экраном.

## Фаза 1. Сервисы

Цель: сеть, кэш, избранное, без экранов. Если это не первый полигон, скопировать `Services/` и `Models/` из предыдущего и только прогнать тесты.

- [ ] `CountryDTO`, `Country`, маппинг.
- [ ] `CountriesAPI` с параметром `fields`.
- [ ] `CountryCache` в Caches, `FavoritesStore` в Documents с потоком `changes`.
- [ ] Тесты: маппинг стран без столицы и с несколькими столицами; повреждённый файл даёт пустое значение; `changes` доставляет новое значение после `save`.

Вопросы себе: почему DTO и `Country` разделены? Что случится, если API добавит поле? Почему кэш в Caches, а избранное в Documents?

Готово, когда тесты сервисов зелёные.

## Фаза 2. Список

Цель: экран списка с кэшем и загрузкой из сети.

- [ ] `CountryCell` с `configure` и загрузкой флага через `Task`, отмена при переиспользовании.
- [ ] `CountriesListViewController`: чтение кэша в `viewDidLoad`, загрузка в `Task`, diffable snapshot.
- [ ] `StateView` для загрузки и ошибки.
- [ ] Тап пушит `CountryDetailViewController`.

Вопросы себе: где в жизненном цикле безопасно запускать загрузку? Что произойдёт с `Task`, если уйти с экрана до ответа? Почему флаг может оказаться в чужой ячейке?

Готово, когда список стран виден на устройстве и с кэшем, и без.

## Фаза 3. Детали и избранное

Цель: детали, кнопка избранного, экран избранного, синхронизация между экранами.

- [ ] `CountryDetailView` и контроллер деталей с кнопкой избранного.
- [ ] `FavoritesViewController` с подпиской на `changes`.
- [ ] Список тоже слушает `changes`, если ячейка показывает признак избранного.

Вопросы себе: три контроллера подписаны на один поток. Кто отвечает за отмену? Что будет, если забыть?

Готово, когда избранное меняется во всех трёх экранах сразу и переживает перезапуск.

## Фаза 4. Поиск, обновление, состояния

Цель: все состояния из `SPEC.md` воспроизводятся руками.

- [ ] `UISearchController`, фильтрация в контроллере, регистр и диакритика через `folding` или `localizedStandardContains`.
- [ ] `UIRefreshControl`, обновление и перезапись кэша.
- [ ] Все состояния из `SPEC.md`: без сети без кэша, без сети с кэшем, пустой поиск.
- [ ] Засечь строки в `CountriesListViewController`.

Вопросы себе: сколько обязанностей у контроллера? Какую проще всего вынести и куда?

Готово, когда отключение сети, повреждённый кэш и пустой поиск дают ровно то, что в спецификации.
