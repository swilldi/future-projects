# Спецификация

## Одним абзацем

Один экран, на нём страница отрывного календаря: дата и факт дня. Страницу отрывают жестом вверх, возвращают жестом вниз, прыгают на дату тапом, возвращаются к сегодня кнопкой. Приложение помнит страницу между запусками. Третьего сентября в выбранное время приходит пуш. Виджет показывает сегодняшнюю страницу и сам переключается в полночь. Сети нет, всё офлайн.

## Экраны

### Главный экран

- Страница по центру. Крупно число, над ним месяц, под ним день недели и год. Ниже факт дня.
- Под страницей всегда виден край следующей, чтобы было понятно, что есть куда отрывать.
- Индикатор «не сегодня», если показанная дата не текущая. Ненавязчиво: тонкая строка или точка.
- Кнопка «Сегодня». Видна только когда показанная дата не сегодня.
- Кнопка настроек, неприметная, в углу.
- Тап по дате открывает выбор даты.

### Настройки

Лист на половину экрана.

- Пуш третьего сентября: вкл/выкл.
- Время пуша. По умолчанию 10:00.
- Показывать сегодня при запуске: вкл/выкл. По умолчанию выкл, календарь остаётся там, где оставили.
- О приложении: источник фактов и лицензия. Обязательно, см. `NOTES.md`.

## Жесты

| Жест | Результат |
|---|---|
| Свайп вверх по странице | Страница отрывается, показывается следующая дата |
| Свайп вниз | Предыдущая страница возвращается на место |
| Тап по дате | Выбор даты |
| Тап «Сегодня» | Возврат к текущей дате |

Отрыв: страница тянется за пальцем. Если отпустить до порога, возвращается на место. После порога улетает, и подложка становится текущей страницей. Анимация прерываемая: новый жест во время полёта не ломает состояние. При срыве лёгкий тактильный отклик.

Горизонтальных жестов нет, чтобы не спорить с системными.

## Факты

- Локальная база `facts.json` в бандле. Ключ: месяц и день в формате `MM-DD`. Значение: список фактов.
- Факт: id, текст до 200 символов, источник, ссылка на источник.
- На странице один факт. При первом показе даты выбирается случайный из списка на этот день и запоминается вместе с датой, чтобы при перезапуске страница выглядела так же.
- Если фактов на день нет, заглушка: «Про этот день пока ничего не известно».
- Первая версия стартует с ручной базой: третье сентября обязательно, плюс десяток дат. Полная база придёт из проекта «Сборщик фактов».

## Уведомление

- Одно, ежегодное, локальное: третье сентября в выбранное время. Триггер календарный с повтором.
- Разрешение запрашивается не при запуске, а при первом включении тумблера.
- Смена времени перепланирует уведомление. Выключение удаляет.
- Текст заголовка и тела придумать самому, см. `NOTES.md`.
- Тап по пушу открывает приложение на странице третьего сентября текущего года.

## Виджет

- Размеры small и medium. Показывает страницу на сегодня: дата и факт. В small факт укорочен или скрыт.
- Обновляется в полночь. Таймлайн: сегодня и завтра, перезагрузка после полуночи.
- Тап открывает приложение на сегодняшней странице.
- Факт в виджете совпадает с фактом в приложении: оба берут его из общего хранилища. Если приложение факт ещё не выбирало, виджет выбирает сам и записывает.

## Состояние и хранение

- Показанная дата и id факта хранятся в `UserDefaults` группы приложения.
- Настройки там же.
- При смене дня, пока приложение открыто: обновить индикатор «не сегодня», страницу не двигать.

## Граничные случаи

- 29 февраля: факты по ключу `02-29`. Отрыв 28 февраля в невисокосный год ведёт на 1 марта.
- Переход года: 31 декабря ведёт на 1 января следующего года.
- Смена часового пояса: «сегодня» считается по текущему поясу устройства в момент проверки.
- Выбор даты ограничен диапазоном 1900…2100.
- Повреждённое сохранённое состояние: сброс на сегодня без краша.
- Отказ в разрешении на пуши: тумблер возвращается в выкл, подсказка открыть системные настройки.

## Сущности

```
Fact
  id: String
  monthDay: String          // "09-03"
  text: String
  source: String
  sourceURL: URL?

CalendarPage
  date: Date                // начало дня по текущему календарю
  factID: String?

Settings
  isNotificationEnabled: Bool
  notificationTime: DateComponents   // hour, minute
  opensOnTodayAtLaunch: Bool
```
