# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками на устройстве, что не проверялось.

## Сборка и тесты

- [ ] `CalendarCore` собирается без warnings.
- [ ] Strict concurrency без ошибок и без `nonisolated(unsafe)`, `@unchecked Sendable`.
- [ ] `swift test` в пакете зелёный, тесты идут без симулятора.
- [ ] swift-format ничего не меняет.

## Ядро

- [ ] В `CalendarCore` нет `import SwiftUI`, `UIKit`, `WidgetKit`.
- [ ] Зависимости входят через `init`. Синглтонов и глобальных переменных нет.
- [ ] `FactRepository`, `PageStore`, `SettingsStore` за протоколами, реализации не утекают в сигнатуры.
- [ ] Идентификатор App Group в одном месте.
- [ ] Модели `Sendable`, структуры там, где хватает структур.

## Даты

- [ ] Ни одного `+ 86400`, `addingTimeInterval` для дней, `Date()` в сравнениях дней.
- [ ] Все «дни» это `startOfDay` по переданному `Calendar`.
- [ ] Ключ факта строится из компонентов, а не через форматтер с локалью.
- [ ] Тесты покрывают 31 декабря, 28 и 29 февраля, смену пояса.

## Состояние и ViewModel

- [ ] Один источник правды: страница живёт в ViewModel, Views её не дублируют.
- [ ] ViewModel не импортирует SwiftUI и не знает о вью.
- [ ] Views без логики дат и фактов, только вызовы действий.
- [ ] `@MainActor` на ViewModel и сервисах, которые трогают платформу.
- [ ] Сохранение в `PageStore` при каждом изменении, а не «когда-нибудь».

## Жесты и анимация

- [ ] Прогресс жеста в ViewModel, не в `@GestureState`.
- [ ] Порог срыва один и назван константой.
- [ ] Прерывание анимации новым жестом не оставляет промежуточного состояния.
- [ ] `accessibilityReduceMotion` учтён.
- [ ] `sensoryFeedback` привязан к событию срыва, не к каждому кадру.

## Уведомления

- [ ] Разрешение запрашивается по действию, не при запуске.
- [ ] Триггер: month, day, hour, minute, без года, `repeats: true`.
- [ ] Один идентификатор уведомления, перепланирование удаляет старое.
- [ ] Отказ в разрешении обработан в интерфейсе.
- [ ] Обработчик тапа открывает нужную страницу.

## Виджет

- [ ] Оба таргета в одной App Group.
- [ ] Таймлайн заканчивается политикой `.after(полночь)`, не `.never` и не `.atEnd` без записей.
- [ ] Провайдер не делает сетевых запросов и тяжёлой работы.
- [ ] Факт совпадает с приложением через общий `FactPicker` и `PageStore`.

## Ошибки и края

- [ ] Пустой список фактов на дату даёт заглушку, не краш.
- [ ] Повреждённые `UserDefaults` дают сброс на сегодня.
- [ ] Нет `!`, `try!`, `fatalError` вне тестов и явно невозможных веток с комментарием.

## Доступность

- [ ] У страницы осмысленный `accessibilityLabel`, дата читается словами.
- [ ] Кнопки с подписями, не только иконки.
- [ ] Dynamic Type до самого большого размера без обрезания.
- [ ] Контраст в тёмной теме.

## Тесты

- [ ] Каждая публичная функция ядра покрыта хотя бы одним тестом на обычный случай и одним на край.
- [ ] Имена тестов описывают поведение.
- [ ] Нет тестов, проверяющих реализацию вместо поведения, например что вызван конкретный метод стора.
- [ ] Что не покрыто и почему, записано в `NOTES.md`.

## Что здесь не проверяем

Скорость, память, размер бандла: проект слишком мал. Локализацию: только русский по спецификации.
