# Отрывной календарь

Приложение для iPhone, которое притворяется бумажным отрывным календарём. На странице дата и один факт про этот день. Страницу можно оторвать и увидеть следующую, вернуть назад, прыгнуть на любую дату и одной кнопкой вернуться к сегодня. Раз в год, третьего сентября, приложение присылает пуш. Ради него всё и затевалось.

## Зачем

Разминочный проект. Вернуть руки в форму на знакомом SwiftUI, но с тремя вещами, которых я не делал руками: анимация под пальцем, локальные уведомления с повтором и виджет. Плюс шутка, которую можно показать друзьям.

## Что будет в первой версии

- Страница календаря: число крупно, месяц, день недели, год, факт дня.
- Отрыв страницы жестом вверх с анимацией, под ней следующая дата.
- Возврат на предыдущую страницу жестом вниз.
- Прыжок на любую дату через выбор даты.
- Кнопка «Сегодня».
- Приложение помнит, на какой странице остановился.
- Ежегодный пуш третьего сентября, время настраивается.
- Виджет с сегодняшней страницей.

## Готово, когда

- Все пункты выше работают на устройстве, не только в симуляторе.
- Ядро (даты, факты, выбор факта) покрыто тестами, тесты зелёные.
- Пуш реально пришёл на устройство в назначенное время.
- Виджет обновился в полночь без запуска приложения.
- VoiceOver читает страницу осмысленно, Dynamic Type не ломает вёрстку.
- Агент прошёл по `docs/REVIEW.md`, блокеров нет.
