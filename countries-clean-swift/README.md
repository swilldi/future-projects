# Страны: Clean Swift

Полигон 6 из 10. Одно и то же приложение «Страны», десять раскладок кода. Здесь: **Clean Swift (VIP), UIKit**.

Родственник VIPER с одним принципиальным отличием: поток данных идёт по кругу в одну сторону. ViewController просит Interactor, Interactor отдаёт Presenter, Presenter отдаёт ViewController. Никто не отвечает тому, кто спросил. Модели на каждый сценарий: Request, Response, ViewModel.

## Зачем

Сравнить два способа нарезать экран на пять частей. В VIPER презентер в центре и все ходят через него. В Clean Swift цикл: каждый знает только следующего. Понять, что это меняет в читаемости, в тестах и в количестве протоколов.

## Что хочу понять

- Однонаправленный цикл VIP и почему он проще отлаживается.
- Тройки моделей Request, Response, ViewModel на каждый сценарий.
- DataStore: как сцены передают данные друг другу без параметров init.
- Worker как переиспользуемая логика между сценами.
- Что из этого оказалось лучше VIPER, а что хуже.

## Что делает приложение

Справочник стран: список с флагом и столицей, поиск, обновление из сети, детали с кнопкой «в избранное», список избранного, кэш для запуска без сети. Полное ТЗ в `docs/SPEC.md`, оно одинаково для всех десяти полигонов.

## Готово, когда

- Три экрана работают на устройстве, запуск без сети с кэшем показывает список, избранное переживает перезапуск.
- То, что эта архитектура объявляет тестируемым (см. `docs/ARCHITECTURE.md`), покрыто тестами.
- Агент прошёл по `docs/REVIEW.md`, блокеров нет.
- В корневом индексе заполнена строка сравнения, а в `docs/NOTES.md` ответы на вопросы из раздела «Что записать в сравнение».

## Как начать

1. `docs/SPEC.md`: прочитать целиком, если это первый полигон, иначе пробежать, оно не менялось.
2. `docs/ARCHITECTURE.md`: прочитать целиком. Это единственное, что здесь отличается от соседей.
3. `docs/STACK.md`: раздел «что почитать» перед соответствующей фазой.
4. `docs/PLAN.md`: идти по фазам. `Services/` можно скопировать из предыдущего полигона.
5. `docs/NOTES.md`: по ходу записывать, что бесит и что нравится. Это и есть результат.
