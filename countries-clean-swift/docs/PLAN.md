## Фаза 0. Каркас

Цель: пустой проект, который собирается.

- [ ] iOS App, жизненный цикл через App Delegate и Scene Delegate, программный UI без сториборда.
- [ ] `.swift-format` в корне, `.gitignore` для Xcode, первый коммит.
- [ ] Папки из `ARCHITECTURE.md` созданы, пустые файлы допустимы.
- [ ] `SceneDelegate` собирает вкладки через конфигураторы сцен.

Готово, когда приложение запускается с пустым экраном.

## Фаза 1. Сервисы

Цель: сеть, кэш, избранное, без экранов. Если это не первый полигон, скопировать `Services/` и `Models/` из предыдущего и только прогнать тесты.

- [ ] `CountryDTO`, `Country`, маппинг.
- [ ] `CountriesAPI` с параметром `fields`.
- [ ] `CountryCache` в Caches, `FavoritesStore` в Documents с потоком `changes`.
- [ ] Тесты: маппинг стран без столицы и с несколькими столицами; повреждённый файл даёт пустое значение; `changes` доставляет новое значение после `save`.

Вопросы себе: почему DTO и `Country` разделены? Что случится, если API добавит поле? Почему кэш в Caches, а избранное в Documents?

Готово, когда тесты сервисов зелёные.

- [ ] Сцена деталей: DataStore с `country`, заполняется роутером списка.
- [ ] Сцена избранного по образцу списка.
- [ ] `FavoritesWorker` с потоком изменений, интеракторы слушают.

🤖 Рутина по желанию: сцену избранного можно отдать агенту по образцу списка, как в VIPER. Если отдал, сравнить качество результата с VIPER: какой шаблон агент выдержал лучше.

Вопросы себе: что произойдёт, если роутер забудет заполнить DataStore? Как это поймать тестом?

Готово, когда избранное меняется во всех трёх экранах сразу и переживает перезапуск.
