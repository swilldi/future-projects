# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Чистые типы

- [ ] `LevelLoader`, `InputState`, `PlayerMovement`, машина состояний без SpriteKit.
- [ ] Тесты движения на высоту, coyote, буфер числами.

## Движение

- [ ] Герой движется через `PlayerMovement`, тело кинематическое.
- [ ] `deltaTime` ограничен.
- [ ] `isGrounded` через счётчик касаний.
- [ ] Параметры движения в одной структуре.

## Контакты

- [ ] Категории из `PhysicsCategory`, битов в коде нет.
- [ ] `didBegin` разбирает пары в одном месте.
- [ ] «Сверху» определяется по нормали или относительной позиции, не по скорости только.
- [ ] Изменения узлов не в физическом шаге.

## Кадр

- [ ] В `update` нет аллокаций и `childNode(withName:)`.
- [ ] Пауза при уходе в фон, возврат без скачка.
- [ ] Звуки прогреты.

## Ввод

- [ ] Оба источника дают одно `InputState`.
- [ ] Геймпад пишет на главном потоке.
- [ ] `jumpJustPressed` живёт один кадр.

## Ассеты

- [ ] Лицензии записаны, размер тайла совпадает со спрайтами.

## Доступность

- [ ] Экранные кнопки с подписями.
- [ ] Экран победы и «Заново» читаются VoiceOver.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн уровня как игры, баланс, графику.
