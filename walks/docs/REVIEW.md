# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Расчёты

- [ ] `Stats/` без CoreLocation и других платформенных типов.
- [ ] Тесты на синтетике: прямая, шум, подъём, туннель.
- [ ] Гистерезис высоты и фильтр точек с порогами из `SPEC.md` в константах.

## База

- [ ] Точки пачками в транзакции, не на главном акторе.
- [ ] Индекс по прогулке и времени.
- [ ] Миграции только добавляются.
- [ ] Наблюдение отменяется при уходе.

## Фон

- [ ] Фоновый режим в plist, `allowsBackgroundLocationUpdates`, автопауза системы выключена.
- [ ] Восстановление незавершённой прогулки.
- [ ] Батарея за час записана.

## Плашка

- [ ] Не чаще раза в 15 секунд, немедленно на паузу и стоп, тест.
- [ ] Завершается при стопе.
- [ ] Интент работает из плашки.

## Разрешения

- [ ] Геолокация при первом старте, HealthKit при первом сохранении.
- [ ] Отказы обработаны, тексты в plist честные.
- [ ] `isHealthDataAvailable` проверен.
- [ ] Координат в логах нет.

## Экраны

- [ ] Карта получает упрощённый маршрут.
- [ ] Графики не получают все точки без упрощения.

## Доступность

- [ ] Показатели читаются с единицами.
- [ ] Графики с `accessibilityLabel` и итогами.
- [ ] Кнопки старт, пауза, стоп с подписями.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, точность GPS сверх фильтра, часы.
