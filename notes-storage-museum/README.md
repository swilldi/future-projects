# Заметки: музей хранилищ

Обычные заметки: заголовок, текст, теги, поиск. Необычное в том, что хранилище переключается в настройках: файлы, UserDefaults, CoreData, SwiftData, SQLite через GRDB. Все пять реализуют один протокол. Отдельный экран гоняет тысячу заметок через каждое и показывает время.

## Зачем

Понять, чем хранилища отличаются на практике, а не по статьям: где удобно писать, где быстро читать, где больно мигрировать. Пощупать CoreData и SwiftData рядом, чтобы увидеть, что второе это первое в новой одежде. Впервые взять SQLite напрямую и прочитать свой SQL.

## Что будет в первой версии

- Список заметок по дате изменения, поиск по заголовку и тексту, фильтр по тегу.
- Создание, редактирование, удаление.
- Пять хранилищ за протоколом `NotesRepository`, переключатель в настройках.
- Экран замеров: вставить 1000, прочитать все, найти, обновить 100, удалить 100, для каждого хранилища.
- Миграция: добавить поле «закреплено» во все пять и не потерять данные.

## Готово, когда

- Все пять хранилищ проходят один и тот же набор тестов протокола.
- Переключение хранилища в настройках работает без перезапуска.
- Таблица замеров заполнена в `docs/NOTES.md` для всех пяти.
- Миграция с добавлением поля прошла во всех пяти на непустых данных.
- В `docs/NOTES.md` ответ на вопрос «что бы я взял для реального проекта и почему».

## Что хочу попробовать

Протокол репозитория с одним набором тестов на все реализации. CoreData: контексты, фоновая запись, `NSFetchedResultsController` как источник изменений. SwiftData: `@Model`, `ModelContainer`, версии схемы. GRDB: миграции, `ValueObservation`, полнотекстовый поиск FTS5. Замеры через `ContinuousClock`. Лёгкая миграция в каждом.

## Как начать

1. Прочитать `docs/SPEC.md` и `docs/ARCHITECTURE.md`.
2. Пробежать `docs/STACK.md`. Раздел «что почитать» смотреть перед соответствующей фазой, не всё сразу.
3. Открыть `docs/PLAN.md` и идти по фазам, отмечая чекбоксы. Агента звать только там, где стоит 🤖.
4. Заметки, решения и вопросы складывать в `docs/NOTES.md`.

## Оценка

Две недели. По два-три вечера на хранилище, вечер на замеры, два на миграцию.
