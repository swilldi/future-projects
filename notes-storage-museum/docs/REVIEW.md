# Чеклист ревью

Для агента и для меня. Идти сверху вниз. Проверять только то, что по `PLAN.md` уже должно быть сделано.

## Формат замечания

`[уровень] файл:строка. Что не так. Почему это проблема. Как исправить в одну строку.`

Уровни: блокер (ломает поведение или архитектуру), важно (сработает позже), мелочь (стиль, читаемость). Код в ответе не переписывать. В конце: что сделано хорошо, что проверить руками, что не проверялось.

## Сборка и тесты

- [ ] Без warnings. Strict concurrency без `nonisolated(unsafe)` и `@unchecked Sendable`, исключения только с комментарием, почему.
- [ ] Тесты зелёные. swift-format ничего не меняет.

## Контракт и домен

- [ ] `Note` без знания о хранилищах.
- [ ] Все реализации проходят `NotesRepositoryContractTests`, тест параметризован, не скопирован пять раз.
- [ ] `changes` срабатывает после каждой записи в каждой реализации.
- [ ] Теги нормализуются в домене, не в хранилищах.

## Общее для хранилищ

- [ ] Запись не на главном акторе.
- [ ] Модели хранилищ не покидают свою папку.
- [ ] Каждое хранилище само создаёт своё место на диске, пути не пересекаются.
- [ ] `deleteAll` действительно удаляет всё, включая FTS-индекс и файлы.

## CoreData

- [ ] Маппинг внутри `perform`.
- [ ] Фоновый контекст на запись, `viewContext` только чтение.
- [ ] Политика слияния задана.
- [ ] Версия модели для миграции добавлена, старая не изменена.

## SwiftData

- [ ] Запись через `@ModelActor`.
- [ ] `#Predicate` для поиска, не фильтрация в памяти.
- [ ] `VersionedSchema` и план миграции.

## GRDB

- [ ] Все записи в транзакциях.
- [ ] Миграции только добавляются, старые не меняются.
- [ ] FTS-таблица синхронизируется триггерами или в той же транзакции.
- [ ] `ValueObservation` отменяется при уходе.

## Замеры

- [ ] Все хранилища замеряются одним кодом через протокол.
- [ ] Данные засеиваются заново перед каждым прогоном.
- [ ] Медиана из трёх, не первый прогон.

## Доступность

- [ ] Список и редактор читаются VoiceOver.
- [ ] Dynamic Type в редакторе.

## Тесты

- [ ] Покрыто то, что `ARCHITECTURE.md` объявляет тестируемым.
- [ ] Тесты проверяют поведение, не последовательность вызовов.
- [ ] Нет `sleep` и ожиданий по таймеру в тестах.
- [ ] Что не покрыто, записано в `NOTES.md` с причиной.

## Что здесь не проверяем

Дизайн, синхронизацию, шифрование.
