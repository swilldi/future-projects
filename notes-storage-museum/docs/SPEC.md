# Спецификация

## Одним абзацем

Заметки с заголовком, текстом, тегами и датами. Список, поиск, фильтр по тегу, редактор. В настройках выбор хранилища из пяти и кнопки «засеять тысячу» и «замерить». Экран замеров показывает таблицу времени по операциям и хранилищам. Хранилища не делят данные: у каждого свой набор заметок.

## Экраны

### Список

- Заметки по дате изменения, новые сверху. Ячейка: заголовок, первая строка текста, теги, дата.
- Поиск по заголовку и тексту, по мере ввода.
- Фильтр по тегу через чипы над списком.
- Свайп: удалить. Кнопка «плюс»: новая.
- Пусто: «Заметок нет» и кнопка «засеять тысячу» для быстрого старта.

### Редактор

- Заголовок, текст, теги через запятую.
- Сохранение при уходе с экрана, без кнопки.
- Даты создания и изменения внизу, только чтение.

### Настройки

- Хранилище: сегмент из пяти. Переключение мгновенное, список перечитывается.
- «Засеять тысячу»: генерирует заметки с осмысленным текстом из встроенного словаря, чтобы поиск было чем проверять.
- «Удалить всё» в текущем хранилище, с подтверждением.
- Кнопка «Замеры».

### Замеры

- Таблица: строки это операции, столбцы это хранилища. Ячейка: время в миллисекундах.
- Операции: вставить 1000 по одной; вставить 1000 пачкой; прочитать все; найти слово, встречающееся в 5 процентах; обновить 100; удалить 100; холодный старт (открыть хранилище и прочитать первые 20).
- Кнопка «запустить всё». Каждое хранилище тестируется на своей копии данных, засеянной перед замером.
- Результаты копируются в буфер как Markdown-таблица для `NOTES.md`.

## Хранилища

| Ключ | Реализация | Что именно |
|---|---|---|
| `files` | `FileNotesRepository` | Один JSON-файл на заметку в папке Documents/notes |
| `defaults` | `UserDefaultsNotesRepository` | Массив заметок как `Data` под одним ключом. Намеренно плохо, чтобы увидеть почему |
| `coredata` | `CoreDataNotesRepository` | `NSPersistentContainer`, сущность `NoteEntity`, фоновый контекст на запись |
| `swiftdata` | `SwiftDataNotesRepository` | `ModelContainer`, `@Model NoteModel`, отдельный `ModelContext` на запись |
| `grdb` | `GRDBNotesRepository` | `DatabaseQueue`, таблица `note`, FTS5 для поиска, `ValueObservation` |

## Миграция

После того как все пять работают: добавить поле `isPinned: Bool` со значением по умолчанию `false`. Закреплённые заметки показываются сверху. Миграция должна пройти на хранилище с данными без потерь:

- файлы: отсутствующее поле при декодировании даёт `false`;
- UserDefaults: то же;
- CoreData: лёгкая миграция, новая версия модели;
- SwiftData: `VersionedSchema` и `SchemaMigrationPlan`;
- GRDB: `DatabaseMigrator` с `ALTER TABLE`.

## Границы

- Заметка с пустым заголовком: заголовок «Без названия».
- Тег с пробелами по краям: обрезать. Дубликаты тегов: схлопнуть.
- Поиск по пустой строке: все заметки.
- Тысяча заметок в UserDefaults: должно работать, но медленно. Это и надо увидеть.
- Переключение хранилища во время замера: заблокировано.

## Не делаем

- Синхронизацию, вложения, форматирование текста.
- Перенос данных между хранилищами.
- Шифрование.

## Сущности

```
Note
  id: UUID
  title: String
  body: String
  tags: [String]
  createdAt: Date
  updatedAt: Date
  isPinned: Bool         // появляется в фазе миграции

NotesRepository (протокол)
  func all() async throws -> [Note]
  func search(_ query: String, tag: String?) async throws -> [Note]
  func note(id: UUID) async throws -> Note?
  func save(_ note: Note) async throws
  func saveBatch(_ notes: [Note]) async throws
  func delete(id: UUID) async throws
  func deleteAll() async throws
  var changes: AsyncStream<Void> { get }
```
